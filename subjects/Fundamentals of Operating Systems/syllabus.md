Prerequisite: Programming, Computer Organization and Architecture, Data Structures and Algorithms
Course Objective
The objective of this course is to provide students with a comprehensive understanding of operating
system principles, including process management, CPU scheduling, synchronization, deadlock
handling, memory management, and I/O systems. The course aims to develop students’ ability to
analyze core operating system mechanisms and to relate theoretical concepts to real-world operating
systems such as UNIX, mobile platforms, and modern heterogeneous computing environments.
Course Outcomes
After completion of the course, students will be able to -
1. Explain the fundamental concepts of operating systems, including OS evolution, system calls, and
resource management.
2. Analyze process management and CPU scheduling techniques, including process states, context
switching, threads, and scheduling algorithms such as FCFS, SJF, Priority, and Round Robin.
3. Apply process synchronization and concurrency control mechanisms using critical sections,
semaphores, monitors, and message passing to solve classical IPC problems.
4. Evaluate deadlock handling strategies and memory management techniques, including deadlock
prevention, avoidance (Banker’s algorithm), paging, segmentation, virtual memory, and page
replacement algorithms.
5. Compare I/O management, disk scheduling, and file management strategies, and relate operating
system concepts to real-world case studies such as UNIX, mobile operating systems, and
heterogeneous architectures.
