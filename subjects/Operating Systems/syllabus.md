Program: B Tech (CE, CSBS, AIDS, AIML, IT, CSECS, CS)   Semester: III/IV
MBA Tech (CE, IT)
Course: Operating Systems   Course Code: 702CO0C078
Teaching Scheme   Evaluation Scheme
Lecture   Practical   Tutorial   Internal Continuous
(Hours   (Hours per   (Hours   Credit   Assessment (ICA)   Term End Examinations
per   week)   per week)   (marks -50)   (TEE) (marks -100)
week)
3   2   0   4   Marks Scaled to 50   Marks Scaled to 50
Prerequisite: Programming, Computer Organization and Architecture
Course Objective
This course aims to provide a comprehensive understanding of operating system principles, including
process management, memory management, file systems, synchronization, system security, and storage
management. Students will develop the analytical skills necessary to design, evaluate, and optimize
operating system components for efficient and secure operation.
Course Outcomes
After completion of the course, the students will be able to –
1.Explain the fundamental concepts of operating systems. (K2)
2.Analyze the various process management techniques and concurrency mechanisms. (K4)
3.Explain synchronization, deadlock handling, and resource allocation methods for efficient process
execution. (K2)
4.Apply knowledge of memory management techniques and page replacement algorithms to
optimize system performance. (K3)
5.Implement I/O management strategies and disk scheduling algorithms for system   performance
improvement. (K3)
6.Utilize case studies to understand the architecture, file system and security mechanisms of
operating system. (K2)
Detailed Syllabus
Unit   Description   Duration
1   Introduction to Operating system:   03
OS objectives and functions, evolution of operating system, Basic concepts:
Processes, Files, System Calls, Basic architectural concepts of an OS, Concept of
Virtual Machine, Resource Manager view,
Process view and hierarchical view of an OS, Real-Time Operating Systems   02
(RTOS) and lightweight OS
2   Process and Process Scheduling:   04
Definition, Process Relationship, Different states of a Process, Process State
transitions, Process Control Block (PCB), Context switching
Process Scheduling: objectives, Types of Schedulers, Scheduling criteria, Pre-
emptive and non-pre-emptive Scheduling algorithms - FCFS, SJF, SRTF, Priority,
and Round Robin. Multilevel scheduling
Thread: Definition, Various states, Benefits of threads, Types of threads   02
Signature
(Head of the Department)   AY 2026-27
SVKM’s NMIMS Deemed-to-be University
Mukesh Patel School of Technology Management and Engineering
3   Process Concurrency:   04
Concurrent processes, precedence graphs, Critical Section, Race Conditions,
Mutual Exclusion, Hardware Solution, Semaphores,   Strict Alternation,
Peterson’s Solution, The Producer / Consumer Problem, Event Counters,
Monitors, Message Passing, examples on live locks.
Classical IPC Problems: Reader’s & Writer Problem, Barber’s shop problem   02
4   Deadlock:   02
Definition, Necessary and sufficient conditions for Deadlock, Deadlock
Prevention
Deadlock Avoidance: Banker’s algorithm, Deadlock detection and Recovery,   04
Dinning Philosopher Problem
5   Memory Management:   04
Basic concepts
Memory allocation: Contiguous Memory allocation – Fixed and variable
partition– Internal and External fragmentation and Compaction.
Basics of Virtual Memory – Hardware and control structures – Locality of
reference, Page allocation, Partitioning, Paging, Page fault, Working Set,
Segmentation, Demand paging, Thrashing.
Page Replacement algorithms: Optimal, First in First Out (FIFO), Belady's   02
anomaly, Least Recently used (LRU), Not Recently Used ( NRU).
6   I/O Management and Disc Scheduling:   02
I/O devices, Direct Memory Access, Principles of I/O, Disk structure.
Disk scheduling - FCFS, SSTF, SCAN, C-SCAN, LOOK and C-LOOK, RAID.   03
7   File Management:   03
Concept of File, Access methods, File types, File operation, Directory structure,
File System structure, Allocation methods (contiguous, linked, indexed),
Free-space management   (bit   vector, linked   list, grouping), directory   03
implementation (linear list, hash table), efficiency and performance, Journaling
and log-structured file systems.
8   Case study:   03
Operating Systems for Heterogeneous Architectures (e.g., GPUs, TPUs),
Unix case study- History, General structure, Unix file system: file abstraction,
directories, mount points, implementation details.
The shell: basic operation, commands, standard I/O, redirection, pipes, signals.
Character and block I/O.
Protection and security: Illustrations of security model of UNIX and other OSs.   02
Examples of attacks, Security aspects in Modern OS
Total   45
