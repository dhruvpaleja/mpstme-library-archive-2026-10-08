Course Objective
This course aims to provide knowledge on information theory for data compression and
implement channel coding techniques for correcting and detecting errors in the
communication channel.
Course Outcomes
After completion of the course, students will be able to -
1. Illustrate the basic concepts of information, entropy, Shannon’s theorem and channel
capacity
2. Implement and analyse various source coding techniques
3. Apply various channel coding techniques for error correction and analyse their
performance.

Unit Description   Duration
