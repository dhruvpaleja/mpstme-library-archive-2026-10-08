Pre-requisite: Digital Design.
Objectives:
1. To provide basic knowledge of digital design flow and hardware description
languages.
2. To provide knowledge of simulation, synthesis and implementation of digital
circuit using VHDL.

3. To describe finite state machine and their design concept.

4. To explain various types of programmable devices.

5. To describe basic technique for testing combinational and sequential logic
circuits.

Outcomes:
After the successful completion of this course, the student will be able to
1. Describe digital design flow and concept of VHDL used for digital circuit
designing.
2. Design and implement different types of digital logic circuits using VHDL.
3. Design finite state machine using VHDL
4. Program CPLD and FPGA using VHDL.
5. Test and diagnose digital logic circuits.
