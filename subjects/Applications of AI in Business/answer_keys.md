Machine Learning

Machine Learning is a subfield of Artificial Intelligence that enables systems to
learn from data and improve their performance over time without being explicitly
programmed for every scenario. Instead of following hard-coded rules, a machine
learning model identifies patterns and makes predictions or decisions based on data.
For example, an e-commerce platform using ML can recommend products to users
by

analysing] their past behaviour and preferences. While AI is the broader concept of
machines performing tasks that typically require human intelligence (such as
problem-solving, language understanding, and perception), machine learning
specifically focuses on the learning aspect—how machines acquire knowledge from
data.

Supervised Learning

’ ("Learning with a Teacher")

The model is trained using labelled data, meaning each input is paired with a known
output.

How it works:

e The algorithm learns a mapping between inputs (features) and outputs (labels)
e During training, it is explicitly told what the correct answer is

e After training, it can predict outcomes for new, unseen inputs

Supervised Learning Algorithms:

a. Classification

i. Predict a category or label for each input

Example: Predicting whether an email is spam or not spam based on its content
b. Regression

i. Predict a continuous value for each input

Example: Predicting house prices based on features like size, location, etc.

How NLP Helps

Understanding Customer Queries: NLP interprets user input (text/voice) — enables
accurate and quick responses.

24/7 Instant Support: Chatbots respond anytime — improves customer satisfaction
and engagement.

Personalization: NLP analyzes past interactions — delivers customized replies and
recommendations.

Multilingual Support: Can handle multiple languages — helps reach diverse
customers.

Intent Recognition: Identifies what the customer wants — supports faster issue
resolution and better decision making.

Challenges

Misinterpretation of Queries: Complex or unclear language may confuse the bot —
leads to wrong responses.

Limited Context Understanding: Struggles with long or emotional conversations —
affects customer experience.

Training Data Requirement: Needs large, high-quality data — poor data causes
ineffective performance.

Handling Edge Cases: Unusual queries may not be answered — requires human
intervention.

Privacy Concerns: Uses customer data — raises security and ethical issues.
