Pre-requisite: Basic understanding of image processing techniques. Familiarity with deep learning
concepts, particularly Convolutional Neural Networks (CNNs). Experience with python
programming and using popular libraries such as TensorFlow / PyTorch /Keras.
Course Objective
The aim of this course is to provide graduates with a comprehensive understanding of computer vision
techniques, covering core methodologies, algorithms, and tools. Students will explore diverse
applications of computer vision, enabling them to apply these techniques effectively in real-world
scenarios across various domains.
Course Outcomes
After completion of the course, students will be able to –
1. Understand image processing techniques, including enhancement, restoration, filtering, and
GAN-based image generation, for real-world applications.
2. Apply feature extraction and object description methods, such as key point detection,
segmentation, and camera geometry, for analyzing moving objects.
3. Implement machine learning models like CNNs, YOLO, and SSD for image classification,
object detection, and model training.
4. Analyze and implement 3D computer vision techniques for various applications, including
healthcare and autonomous driving.
