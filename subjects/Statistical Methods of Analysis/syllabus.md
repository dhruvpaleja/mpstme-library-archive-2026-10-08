Course Objective
This course assists in research using statistics for a given data and testing of hypotheses using various
statistical tests. It also provides explanations and expositions of statistical concepts pertaining to handling
large datasets and to get meaningful insight or inferences from them.
Course Outcomes
After completion of the course, the student will be able to -
1. Classify the data using various visualization techniques
2. Evaluate the various measures of central tendency and dispersion for a given data
3. Estimate mean of large samples using probability and sampling distributions
4. Test hypothesis using parametric and non-parametric inferential statistical tests
