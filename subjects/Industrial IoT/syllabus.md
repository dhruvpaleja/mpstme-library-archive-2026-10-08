2   2   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Nil
Course Objective
This course is used for connecting devices and making them more available and intelligent to enhanced
the manufacturing and industrial process. It also provides key practical insights to implement web
based industrial processes into the field such as logistics, oil and gas, transportation, mining and metals,
aviation and other industrial sectors.
Course Outcomes
After completion of the course, the student will be able to -
1. Understand IIoT architecture and networking protocols
2. Compare various cloud platforms based on cloud services
3. Apply data visualization techniques on IIoT data
4. Explain security aspects related to IIoT
Detailed Syllabus
Unit   Description   Duration
1.   Introduction of Industrial IoT (IIoT)
What is industry 4.0 and factors that enable IIoT, definition, IIoT value chain who
does what, IoT vs IIoT, Key skills required for IIoT, Application areas: for example,   02
Automotive, Transportation, Industrial Manufacturing, Building Automation, Oil
& Gas, and Agriculture etc.
2.   IIoT Architecture
IIoT methodology, IIoT Reference Architecture, IIoT Components - Sensors,   04
Gateways, Routers, Cloud brokers, Servers and their integration, Software and
Services market in IIoT.
3.   IIoT Networking
Networking Protocols - 6LowPan, RPL, Application-Level Protocols- MQTT,   07
CoAP, AMQP, REST, Back-end Application Designing - Handling HTTP Requests,
PHP, MySQL, JSON lib for data processing.
4.   IIoT Cloud Platforms
Overview of COTS cloud platforms - Predix, Thingworks, Azure etc. Cloud   07
services, Business models: Saas, Paas, Iaas.
IoT Analytics - Role of analytics in IIoT, Data visualization techniques used in IIoT.
5.   Security
Conventional web technology and relationship with IIoT, Vulnerabilities of IIoT,   03
Privacy, Security requirements, Identity establishment, and Access control.
