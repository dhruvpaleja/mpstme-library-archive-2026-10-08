Pre-requisite: Basic Knowledge of Computer Network, Operating Systems and programming
Course Objective
To impart knowledge to Critically assess organisation's security and be able to
apply managerial, technical, operational security controls to improve organisation's security.
Course Outcomes
After completion of the course, the student will be able to -
1. Identify and apply key elements of managerial and operational security practice
2. Analyse and evaluate a company of your choosing and compile a formal risk
assessment of your analysis, findings, and suggest actions for the company to take
through interpretation of your findings
3. Identify key elements of technical security and be able to explain how they function
and how and where they may be usefully applied
4. Use technical security software and identify how and where it may be usefully applied
Detailed Syllabus
Unit   Description   Duration
1   Introduction to Information Security
Overview,   definition,   information   security   concepts,   threats,
vulnerabilities and security controls, attack (active and passive attacks)   5
with examples, security design principles, methods of defenses, security
policies and its types, legal and ethical aspect
2   Cryptography
Cryptography basics, transposition and substitution ciphers, symmetric
and asymmetric cryptographic algorithms (AES, Diffie Hellman, and   7
RSA), stream and block ciphers, key management, digital signature, hash
functions, Attacks on cryptosystems.
3   Program Security
Secure programs, Non malicious Program Errors, malicious software,   4
database security, countermeasures.
4   User Authentication   2
Authentication basics, factors of authentication, password based
authentication, token based authentication, biometric authentication,
remote user authentication, security issues
5   Access control   3
Access control principles, discretionary access control, mandatory access
control, role based access control, identity, credential, and access
management, trust frameworks
6   Security Technologies   5
AY 2025-26
Firewalls, types of Firewalls, Filtering Services, DMZ, Implementing
policies (Default allow, Default Deny) on proxy, NAT, Intrusion
Detection and Prevention Systems, types of IDPS, Security information
and event management (SIEM)
7   Risk Management   4
Overview of risk management, risk identification and assessment, risk
control strategies, selecting risk control strategy, continuity strategies
(Business continuity planning, Incident response planning, Disaster
Recovery planning)
Total   30
