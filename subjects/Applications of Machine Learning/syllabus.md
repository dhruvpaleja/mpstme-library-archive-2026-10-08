Pre-requisite: Foundations of Machine Learning
Course Objective
The aim of the course is to provide progressive understanding of pattern classification and
algorithms in order to classify multivariate data. It will also give information on the interpretation
and implementation of the various genetic algorithms. Further, it will help students acquire
knowledge of Q-Learning methods which will aid them in developing new machine learning
techniques.
Course Outcomes
After completion of the course, students will be able to -
1. Apply various classification and regression algorithms to categorize multivariate data and
find relationship between data variables
2. Analyze reinforcement learning algorithms to test various complex systems
3. Evaluate different computational learning methods and results using scientific reports
