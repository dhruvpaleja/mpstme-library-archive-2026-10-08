Pre-requisite: Computer Vision and Applications
Course Objective
The aim of this course is to deep dive into details of neural-network based learning methods for
computer vision. It will cover neural learning algorithms and practical engineering tricks for
training and fine-tuning networks for visual recognition tasks. It will enable the students to learn
advanced concepts of computer vision and utilize them to implement vision algorithms efficiently
for use in research and industry.
Course Outcomes
After completion of the course, students will able to –
1. Analyze visual content using feature extraction techniques such as edge, corner, blob
detection, and descriptors like SIFT, SURF, HoG, and LBP for effective image
representation and matching.
2. Apply Convolutional Neural Networks (CNNs) for image classification, recognition, and
training using advanced architectures such as AlexNet, VGG, ResNet, and Inception.
3. Demonstrate the integration of CNN and RNN models for spatio-temporal tasks including
video-based action recognition, image captioning, and sequence-to-sequence problems.
4. Evaluate object detection and segmentation methods (e.g., YOLO, Mask R-CNN, U-Net),
and visualize CNN features using techniques like DeepDream and Style Transfer.
5. Design and implement advanced deep learning models for generative and self-supervised
tasks using GANs, VAEs, contrastive learning, and video understanding using 3D CNNs
and multimodal systems.
