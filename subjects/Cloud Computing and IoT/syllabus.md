Pre-requisite: Programming for Problem Solving, Computer Networks, Microprocessor
and Microcontroller
Objectives:
1. To provide the fundamental knowledge of cloud computing techniques and IoT
frameworks
2. To provide the correlation of the components, processes and mechanisms of cloud
infrastructure and IoT
Course Outcomes:
After completion of the course, students would be able to:
1. Identify the components, techniques and frameworks for cloud computing
2. Describe the cloud infrastructure, cloud service deployment models and lifecycle
3. Analyze the processes and design methodology for IoT frameworks
4. Apply the concepts on hardware kits and simulation using programming languages
Detailed Syllabus: (per session plan)
Unit   Description   Duration
1   Introduction to IoT: Introduction, Physical design of IoT, Logical   03
design of IoT, IoT enabling technologies, IoT levels. Machine-to-
machine and IoT Technology Fundamentals
2   IoT Design Methodology: Purpose and requirement specifications,   05
process specifications, domain model, information model, service
specifications, IoT level specifications, functional view, operational
view, device and component integration, application development
3   IoT programing for Application Development: Different types of IoT   08
devices, Raspberry Pi, Arduino Uno interfaces, Programming IoT
devices using C/C++ and Python, Simulation using Tinkercad
4   Introduction to Cloud Computing: Cloud Computing definition,   06
characteristics of cloud computing, private, public and hybrid cloud.
Cloud types; IaaS, PaaS, SaaS. Benefits and challenges of cloud
computing, public vs private clouds, role of virtualization in enabling the
cloud; Business Agility: Benefits and challenges to Cloud architecture.
Next generation Cloud Applications.

Computing, cloud computing reference model, cloud infrastructure
