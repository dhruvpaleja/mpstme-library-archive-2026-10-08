Pre-requisite: Applications of Machine Learning
Course Objective
The aim of the course is to introduce students with the essentials of speech and natural language
processing (NLP). The essentials cover linguistic aspects, core algorithms for solving basic tasks, statistical
machine learning models for several natural language processing tasks. It will also cover algorithms for
speech processing, linguistic information and the computational properties of natural languages.
Course Outcomes
After completion of the course, students will be able to –
1. Apply basic text processing techniques such as tokenization, stemming, and normalization using
NLP libraries. (L3 – Apply)
2. Build and analyze language models using N-grams, smoothing techniques, and neural network-
based approaches. (L4 – Analyze)
3. Implement syntactic parsing and part-of-speech tagging using probabilistic and dependency
parsing methods. (L4 – Analyze)
4. Apply distributional and lexical semantics techniques for clustering, word sense disambiguation,
and semantic analysis. ((L5 – Evaluate))
5. Design and develop NLP applications using advanced models such as encoder-decoder
architectures, attention mechanisms, and transformers like BERT. (L6 – Create)
