Course Objective
This course would enable students to create dynamic web sites using ASP.NET as a web
development platform of the .NET framework. C# would be the language used for writing
application code and ADO.Net technology as database control for retrieving, manipulating, and
updating data.

After completion of the course, the student will be able to -
1. Develop a project using ASP.Net with basic C# and Object Oriented C#
2. Create dynamic web applications using ASP.NET
3. Implement backend database with controls using ADO.Net technology
