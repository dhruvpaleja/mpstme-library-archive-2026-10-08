Pre-requisite: Basic Knowledge of Computer Network, Operating Systems and programming
Course Objective
This course is an introduction to the field of digital forensics and incident response. This course
introduces various aspects of digital forensics and incident response to the students. Students will
learn about various methods, tools and techniques to perform forensic operations on a given media.
Course Outcomes
After completion of the course, the student will be able to -
1. Perform various forensics operations on a given media
2. Describe various phases of incident response and identify Indicators of Compromise (IoC)
3. Describe various professional, ethical and legal issues related to digital forensics and
Incident Response
Detailed Syllabus
Unit   Description   Duration
1.   Introduction to cybercrime and cyber forensics   09
Definition of cybercrime, type and classification of cybercrimes, Overview of
cyber forensics, forensic process, types of investigations, digital evidence, data
acquisition and forensic imaging, digital forensic tools.
2.   File System Analysis   06
Understanding file systems, booting process, disk drives and solid-state
devices, FAT and NTFS file systems, partition table and MFT, understanding
whole disk encryption, Windows registry, Linux and Mac file structure.
3.   Data Analysis   07
Preparation for forensic analysis, data carving, recovering graphics files and
header analysis, email and internet activity analysis, data hiding techniques,
malware analysis
4.   Network Forensics   04
Overview, analyzing network traffic, network-based evidence, investigating
routers.
5.   Mobile Device Forensics   04
Mobile phone basics, inside mobile devices, acquisition procedure for mobile
devices, mobile forensic tools.
6.   Dark Web forensics and anti-forensics techniques   03
7.   Security Incident Response   08
Stages in IR, IR charter and CSIRT, IR plan and playbook, Indicators of
Compromise (IoC), integrating digital forensics and incident response

Reference Books
