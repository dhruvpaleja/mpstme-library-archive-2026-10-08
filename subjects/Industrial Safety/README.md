# Industrial Safety

**20** unique papers (20 copies across programmes) · 2006-07 to 2022-23 · 1 programme · Sem 6, Trim 8

Download only this subject, sorted by academic year:

```powershell
python organize_by_subject.py restore --destination D:/Study --subject "Industrial Safety"
```

Answer keys, where the portal published them, are in `answer_keys.md`. See [`question_bank/README.md`](../../question_bank/README.md) for the fields.
