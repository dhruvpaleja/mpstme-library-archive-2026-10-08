Pre-requisite: Operating System, Computer Networks
Course Objective
This course is an in-depth study of Cloud security. It aims at providing adequate exposure to the
security measures adopted in Cloud. Students will learn various security issues along with
techniques and ways to protect cloud.
Course Outcomes
After completion of the course, the student will be able to -
1. Classify the cloud reference model and its usage
2. Examine Cloud Security w.r.t data, Platform, Infrastructure, application and operations
3. Evaluate the legal, ethical and compliance aspects of cloud
Detailed Syllabus
Unit   Description   Duration
1.   Cloud Concepts and Reference Architecture   05
Cloud Computing Definitions, Cloud Computing Characteristics, Cloud
Service Categories, Cloud Deployment Models, Cloud Shared Considerations.
2.   Cloud Data Security   05
Data Security Technologies and Strategies, Data Dispersion, Encryption and
Key Management, Hashing, Masking, Tokenization, Data Classification,
Mapping, Labelling, Sensitive data, Data Loss Prevention (DLP), Data
Obfuscation, Data De-identification, Design and Implement Information
Rights Management (IRM), Objectives, Appropriate Tools, Data Retention
Policies, Data Deletion Procedures and Mechanisms, Data Archiving
Procedures and Mechanisms.
3.   Cloud Platform and Infrastructure Security   05
Analyze Risks Associated with Cloud Infrastructure, Risk Assessment and
Analysis, Cloud Vulnerabilities, Threats and Attacks, Virtualization Risks,
Counter-measure Strategies, Design and Plan Security Controls, Physical and
Environmental   Protection, System and Communication   Protection,
Virtualization Systems Protection, Identification, Authentication and
Authorization in Cloud Infrastructure, Audit Mechanisms, Plan Disaster
Recovery (DR) and Business Continuity (BC), Risks Related to the Cloud
Environment, Business Requirements.
