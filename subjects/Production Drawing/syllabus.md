Course Objective
Production drawing is essential for communicating ideas in manufacturing industry as well as other
engineering applications. Production drawings illustrate a set of instructions to manufacture a
product, providing information about dimensions, materials, finishes, tools required, and methods of
assembly and so on. Therefore, this course developed for interpretation and preparation of the
production drawing.
Course Outcomes
After completion of the course, students would be able to -
1. Draw production drawing and conventional symbols of machine parts
2. Create sectional views and detailed drawing based on the given data
3. Recognize the intersections of two or more solids in AutoCAD platform
4. Integrate emerging technologies and real-world applications in production drawing
5. Create the assembly drawings using CAD tools
