Course Objective
This course gives an introduction to Human Computer Interface and provides an
understanding of user centered design process. It will help students to design and
evaluate interactive systems keeping users in mind.
Course Outcomes
After completion of the course, students will be able to -
1. Discuss the importance of good interface design for human computer interaction
2. Apply design principles, models and evaluation techniques to user interface design
3. Identify various aspects of user experience and design thinking in HCI
4. Design user interface application using HCI concept
