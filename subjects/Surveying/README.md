# Surveying

**15** unique papers (17 copies across programmes) · 2011-12 to 2025-26 · 4 programmes · Sem 3, Sem 4, Sem 5, Sem 7, Trim 6

Download only this subject, sorted by academic year:

```powershell
python organize_by_subject.py restore --destination D:/Study --subject "Surveying"
```

Answer keys, where the portal published them, are in `answer_keys.md`. See [`question_bank/README.md`](../../question_bank/README.md) for the fields.
