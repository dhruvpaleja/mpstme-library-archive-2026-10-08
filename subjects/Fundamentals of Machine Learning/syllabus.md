Pre-requisite: Computer Programming, Linear Algebra, Calculus, Probability
Course Objective
This course provides a concise introduction to the fundamental concepts in machine learning
from a practical perspective. Also, it covers the different learning algorithms, paradigms and
frameworks used in Machine Learning.
Course Outcomes
After completion of the course, students will be able to –
1. Identify machine learning techniques suitable for a given problem
2. Apply regression model to solve problems in machine learning domain
3. Analyze and apply classification and clustering algorithms on data.
