Course Objective
Natural Language Processing (NLP) is a contemporary, practical oriented course, which has paved a
way for numerous real world application like information extraction and retrieval, language translation,
sentiment analysis, machine translation, Large Language Models etc. The objective of this course is to
introduce various natural language processing techniques and algorithms for text preprocessing, word
level analysis, syntax analysis and semantic analysis, pragmatic and discourse analysis.
Course Outcomes
After completion of the course, students will be able to -
1. Describe the fundamental concepts and techniques of natural language processing
2. Apply text preprocessing, word level analysis and syntax level analysis techniques on textual
data
3. Implement approaches for semantic level analysis and pragmatic level analysis
4. Illustrate various real world applications of NLP

challenges.

across NLP applications.
