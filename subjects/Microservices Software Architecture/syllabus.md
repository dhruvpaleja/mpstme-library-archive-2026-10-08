Pre-requisite-   Object-Oriented Programming,   Java Programming, Web

Objectives- This course helps students to gain in-depth knowledge of Microservice-
Based System Architecture. Students will gain knowledge to develop a Microservice
for real-life scenario
Outcomes- After completion of the course, students will be able to
1. Explain the concepts of Microservices and its architecture,
2. Design, develop and test Microservices using Spring Boot,
3. Understand the concepts of Microservices governance, security and
migration.
Detailed Syllabus: ( per session plan )
Unit Description   Duration
1   Microservice Evolution:   03
Monolithic Architecture, Limitation of Monolithic, Service
Oriented Architecture and its concepts, Web Services, Need for
Microservices   Architecture, comparing   the   Microservice
Architecture with SOA, Capabilities, features of MSA and
business goals, Applications of MSA.
2   Microservice Architecture:   05
Overview of architectural styles, Microservice architecture as
architectural style, Key architectural elements of MSA, Design
Principles   of   Microservices, Communication models   for
Microservices, Synchronous and Asynchronous communication,
Microservice Transaction Management, benefits and drawback of
Microservices Architecture.
3   Introduction to Spring Boot:   04
Introduction to Spring Boot Framework, Prerequisite of Spring
Boot, Spring boot features, Spring Boot Architecture, Installation
and configuration, Creating Spring boot project, Project
Components, Deploy the project.

4   Design and Development of Microservices:   04
Microservices and Domain-Driven   Design,   Microservice
Boundaries, Microservices Design Patterns- Decomposition
patterns, Integration patterns, Database patterns, Observability
Patterns, Cross-cutting concern Patterns.
5   Building Microservices with Spring Boot:   06
Setting up a development environment, Introduction to HTTP,
REST and REST principles, Using Spring Boot to build RESTful
Microservices, Getting started with Spring Boot, Developing the
Spring Boot Java Microservices using STS, The Spring Boot
configuration, Spring Repository.
6   Database Management in MSA:   05
Monolithic application and shared database, Database per
Microservice, Sharing data between Microservices, CQRS,
Transaction   with   Microservices-   Avoiding   Distributed
transactions with Two-Phase Commit, Publishing Events using
Local Transactions, Database log mining, Event sourcing, Saga.
7   Integrating Microservices:   04
Need   for   integration, Microservices Integration   Patterns,
requirements of integration services, Service orchestration, Service
integration using Spring Boot.
8   Microservices Testing & Registry:   05
Need of testing, types of testing, testing of overall system, Testing
individual Microservices, consumer-driven contract tests, testing
technical standards, Service Registry and Discovery, Service
registry and discovery using spring boot, API Gateway.
9   Deploying and Running Microservices:   05
Containers and Microservices, Introduction to Docker, Deploying
Microservices with Docker, container orchestration, Microservices
deployment patterns, Continuous Integration, delivery and
deployment.
10   Microservices Security and migration:   04
Basic   security   requirements,   Securing   Service-to-service
communication, The Edge Security-OAuth 2.0, Access control-
XACML, Embedded PDP,JWT. OAuth Implementation using
Spring Boot Security. MSA Migration-Advantages, issues, process,
disadvantages.
Total   45
