Prerequisite: C Programming, Computer System Architecture, Data Structures.
Course Objective
The objective of this course is to provide an introduction to the functions of the computer operating
system.
Course Outcomes
After completion of the course, students will be able to -
1. Describe the fundamental concepts of the Operating system
2. Apply process management strategies
3. Demonstrate the concept of Process Synchronization and dealing with real time problems
4. Simulate memory management and file management strategies.
5. Implementing I/O Management concepts.
Detailed Syllabus
Unit   Description   Duration
1.   Introduction to Operating System and Process   03
Operating system services, System calls and their types, Layered Operating
System, Monolithic and Microlithic Architectures, Case study on current
trending OS and its feasibility.
2.   Process Management.   06
The process concept, Process Description, Process Control Block (PCB),
Threads, Thread management, Types of Scheduler, CPU Scheduler, Process
Scheduling, Scheduling Algorithms: FCFS, SJF, Priority, Round Robin. Cron
Scheduling
3.   Interprocess Synchronization and IPC   06
Principles of Concurrency, Process Synchronization, Mutual exclusion concept,
Semaphores, Types of Semaphores, Classical problems in concurrent
programming: Producer/Consumer Problem & Readers/Writers Problem
4.   Deadlock: Principles of Deadlock, Deadlock Prevention, Deadlock Avoidance:   05
Banker’s algorithm, Deadlock detection and Recovery,
5.   Memory Management   05
Contiguous Allocation: Partition (Static & Dynamic), Segmentation, Non-
Contiguous Allocation: Paging, Page Replacement Algorithms: FIFO, LRU,
OPT
6.   I/O Management & File Management   05
