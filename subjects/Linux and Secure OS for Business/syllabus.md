Pre-requisite: Fundamental Knowledge of OS
Course Objective
Build foundational knowledge of the Linux operating system and file system. Emphasizes building
skill using a command line operating system for system administration and security management
tasks. Discusses the purpose, use, architecture, and navigation of the Linux file system. Builds an
understanding and application of file and directory management, process management, text
manipulation, and permissions. Focuses on shell scripting for process automation, configuration
and process management, and security applications. Emphasizes hands-on experience securing
and hardening the Linux operating system.
Course Outcomes
After successful completion of the course, students will be able to -
1. Use Linux command line for various system administration tasks
2. Secure Linux OS
3. Write shell scripts for various tasks
Detailed Syllabus
Unit   Description   Duration
1.   Introduction to Linux OS   3
Linux OS distributions, installation, working with command line , shell
features, PATH and environment variables, regular expressions and grep
command, compression commands, getting help from system, trouble
shooting
2.   Disk Management   3
Understanding disk devices, disk partitioning, file system, mounting,
troubleshooting tools, uuid’s and logical volume management.
3.   System Management   3
Booting process, boot loaders, init and runlevels, job scheduling, logging,
memory management, resource monitoring, package management, process
management

4.   User Management   4
Becoming super user, creation of user and group, deletion of user and group,
user password management, user profiles, managing file permissions and
ownership, setting up public key authentication.
5.   Security   4
SUID, SGID, Sticky bit, ACL, file links, iptables, encrypting and decrypting
disks, backup and restore, system logging
6.   Network management   4
Configuring network interface, network sniffing, troubleshooting network
problems, ssh client and server configuration, Configuring apache web server
