Pre-requisite- Operating System, Computer Network, Distributed Computing
Objectives- This course helps students to build concepts regarding the fundamental
principles of High-Performance Computing. This also create an awareness of the
major technical challenges in high performance computing.
Outcomes- After completion of the course, students will be able to
1. Understanding the trends in Technology and Cost and pipelining
techniques,
2.   Distinguish various hierarchical memory technologies,
3. Implementing parallel algorithms using different techniques like instruction
– level, data – level, and Thread – level,
4. Analyze programming models and workloads in warehouse-scale
computers.
