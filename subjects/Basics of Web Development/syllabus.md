Pre-requisite: Nil
Course Objective
This course aims to help course learners to be able to understand Web design environment and the
principles of Web design, then continue to plan site layout and navigation, and progress to Web
typography, colours and images, working with CSS. Will be able to create dynamic web pages
using a combination of HTML, CSS, JavaScript and PHP, apply essential programming language
concepts when creating HTML forms, select an appropriate web hosting service, and publish for
the world to admire your website.
Course Outcomes
After completion of the course, student will be able to -
1. Understand the basic process of creating and hosting a website
2. Design HTML features to create a webpage
3. Apply CSS styling to HTML pages to control the appearance
4. Creating HTML Form validations on client side with JavaScript and server side with PHP
Detailed Syllabus
Unit   Description   Duration
1   Introduction to Website Development   3
Web Hosting, Domain Name Service, Tools used in Web Development, Network
and Internet, Client Server Web structure.
2 HTML Basics for designing web pages   7
HTML5: basic tags, working with Images, Tables, Links, ordered and unordered
Lists, Styles, Frames, Forms: HTML Forms User Input, Form Elements. HTML
Form Validation on Client side using JavaScript and HTML Form Validation on
Server side using PHP, Get and Post Method.
3   JavaScript Programming for Validations   6
Syntax of JavaScript: data types, operators, variables, tag, Document Object
Model (DOM), Selection statement if and switch, Iterative statements: for, for/in,
while and do while, break and continue, Static vs Dynamic Webpages, Alerts,
Prompts and Popups. Form Validation using JavaScript.
4 CSS for Web Styling   7
Internal, Inline and External CSS, Setting Colors, Common CSS Properties,
Controlling the Page Layout, Font, images, background.
5 PHP for server-side validations   7
Variables, constants, data types, operators, arrays, functions, Selection statement
if and switch, Iterative statements: for, for each, while and do while, forms,
database connectivity using MySQL, Handling session and cookies.
Total   30
