## B TECH INTEGRATED · Mechanical · batch 2019-2025 · Sem 10

- Course as printed: Automatic Control Systems (code BTIME10010)
- Source: `04_Syllabi_Archive/B TECH INTEGRATED/Mechanical/Batch ( 2019 - 2025 )/Semester -10.pdf`, page 5-7

````text
Program: B Tech Integrated (Mechanical Engineering)   Semester: X
Course: Automatic Control Systems   Code: BTIME10010
Teaching Scheme   Evaluation Scheme
Lecture   Practical   Tutorial   Internal Continuous   Term End
(Hours per (Hours per   (Hours per   Credit   Assessment (ICA)   Examinations (TEE)
week)   week)   week)   (Marks - 50)   (Marks- 100)
3   2   0   4   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Engineering Mathematics-II, Engineering Mathematics-III, Fluid Mechanics, Industrial
Electronics
Course Objective
The objective of this course is to familiarize students with the feedback control systems along with
modelling of mechanical, electrical systems from control engineering perspectives and introduce
different methods for system stability evaluation.
Course Outcomes
After completion of the course, the student will be able to –
1.   Identify and analyze different types of control systems
2. Determine the system governing equations for electrical, thermal, mechanical, electro-
mechanical models
3. Evaluate the gain of the system using block diagram and signal flow graph
Detailed Syllabus
Unit   Description   Duration
1.   Introduction   05
Concept of automatic controls, Open loop and closed loop systems, Basic
structure of feedback control system, requirements of an ideal control system,
Feedforward-Feedback control systems, Multivariable control systems.
2.   Modelling of Physical Systems   15
State Variables Models, Impulse response Models, Laplace Transform and its use
in control system’s analysis, Transfer Function Models, Generalized block
diagram of Feedback System, Rules of Block Diagram Algebra, Reduction of block
diagram, Signal flow graphs, Mason’s gain formula.
Models of Mechanical, Electrical, Thermal, Hydraulic and Pneumatic Systems,
Models of Operational Amplifier Circuits for implementing Proportional-
Integral-Derivative Modes of control.
3.   Transient and Steady State Response Analysis   09
Concept of Stability, Absolute Stability, Relative Stability, and Steady-State Error,
BIBO-Bounded Input Bounded Output Stability, Zero-Input stability, First order
and Second order systems, Routh’s stability criterion.
4.   Root Locus Method for Analysis and Design of Control System   08
Concept of Root Locus, Construction of Root Locus Plots, Lead and Lag
compensation.
````
