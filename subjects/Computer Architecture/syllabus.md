Course Objective
This theory course introduces the internal structure, functioning, and organization of computer
systems. It covers data representation, instruction execution, CPU architecture, memory hierarchy, and
I/O organization. The course forms the foundation for advanced topics such as operating systems,
embedded systems, and computer architecture design.
Course Outcomes
After completion of the course, students will be able to -
1. Identify the major functional units of a computer system and their roles.
2. Explain number systems, data representation formats, and basic arithmetic operations
used in computer hardware.
3. Illustrate instruction formats, addressing modes, and the complete instruction execution
cycle.
4. Analyze the impact of memory hierarchy, cache mapping techniques, and virtual
memory performance.
5. Differentiate between various I/O mechanisms such as programmed I/O, interrupt-
driven I/O, and DMA.
6. Evaluate processor performance considering pipelining, hazards, and RISC vs. CISC
design principles.
