b.   Explain the function of BUSY and TEST signals in synchronization

(Description of Busy Signal-2.5M & Description of Test signal-2.5M)
Ans: The 8086 and 8087 work in parallel, but proper coordination is
required to ensure that the CPU does not proceed before the coprocessor
completes its operation. This synchronization is achieved using the
BUSY and TEST signals.
BUSY Signal (from 8087)
• The BUSY signal is generated by the 8087.
•   It indicates whether the coprocessor is currently executing a
floating-point instruction.
• When the 8087 starts execution, it sets BUSY = HIGH.
CO- 4;   • This informs the 8086 that the coprocessor is still processing.   [05]
BL-4
TEST Signal (to 8086)
• The TEST pin of 8086 is connected to the BUSY pin of 8087.
• The 8086 continuously monitors this TEST input.
• As long as TEST = HIGH (BUSY = HIGH), the 8086 knows that
8087 is still busy.
The assembler inserts a WAIT instruction after a coprocessor
instruction.
When 8086 executes WAIT:
•   It enters a loop and keeps checking the TEST pin.
•   It does not proceed further until TEST becomes LOW.
When the 8087 finishes execution:
•   It clears BUSY (sets it LOW).
• This makes TEST = LOW at the 8086.
The 8086 detects this and resumes normal execution.

1.Fixed Priority Mode:
This is the default priority mode.
Working:
•   Priority is fixed from IR0 (highest) to IR7 (lowest).
•   If multiple interrupts occur, the PIC services the highest priority
request first.
•   Lower-priority interrupts are blocked until higher-priority ISR
completes.
Features:
• Simple and predictable.
Q3   • Supports nested interrupts (higher priority can interrupt lower
CO-2;   priority ISR).   [10]
BL-2   Example:
If IR2 and IR5 occur simultaneously → IR2 will be serviced first.
2.Rotating priority Mode:
This mode changes priority dynamically after each interrupt service.
Working:
•   After servicing an interrupt, that level becomes the lowest
priority.
•   Priority rotates among IR lines.
Types:
• Automatic Rotation
•   Specific Rotation (via command words)
Features:
• Ensures fairness among devices.
• Prevents starvation of lower-priority interrupts.
Example:
Initial priority: IR0 > IR1 > IR2 > … > IR7
After servicing IR2 → New priority: IR3 > IR4 > … > IR1 > IR2

3. Specially Fully Nested Mode
Used in cascaded 8259 systems
Working:
• Allows interrupts from a slave PIC to be serviced even if the
master PIC is handling another interrupt.
• Improves nested interrupt handling in multi-level systems.
Features:
• Useful in complex systems with multiple interrupt controllers.
• Maintains proper hierarchy between master and slave PICs.
4.Special Mask Mode
This mode changes how masking affects priority.
🔹 Working:
•   In normal mode, masked interrupts are ignored.
•   In Special Mask Mode, masked interrupts do not affect priority

Features:
• Provides more flexible control over interrupt masking.
• Useful for advanced interrupt management.
•   5.Polling Mode

Working:
• CPU polls the PIC instead of receiving hardware interrupts.
• PIC returns the highest priority pending interrupt.
Features:
• Useful when interrupts are not desired.
• CPU actively checks for requests.

8086 Microprocessor has a 20-bit address bus, which allows it to address 1
MB of memory (since 220 = 1,048,576 bytes or 1 MB).
The 8086 can generate 20-bit memory addresses, which gives it the ability to
access 1 MB of memory (from address 0x00000 to 0xFFFFF).
In hexadecimal, 1 MB is represented by the address range from 0x00000 to
0xFFFFF.
16-bit data bus: The 8086 can transfer 16 bits of data at a time (2 bytes),
meaning it processes data in 16-bit chunks.
Memory Segmentation allows the 8086 to access different types of data (like
code, data, stack, and extra) in separate areas, and each segment can be up to
64 KB in size.
The 8086 divides memory into four main segments:
1. Code Segment (CS): Stores program instructions
2. Data Segment (DS): Stores data
3. Stack Segment (SS): Used for stack operations
4. Extra Segment (ES): Additional data storage
Each segment can be up to 64 KB in size.

• CY, the carry flag − This carry flag is set (1) whenever there is
a carry out from the D7 bit. It is affected after an 8-bit addition or
subtraction operation. It can also be reset to 1 or 0 directly by an
instruction such as "SETB C" and "CLR C" where "SETB" stands
for set bit carry and "CLR" stands for clear carry.
• AC, auxiliary carry flag − If there is a carry from D3 and D4
during an ADD or SUB operation, the AC bit is set; otherwise, it
is cleared. It is used for the instruction to perform binary coded
decimal arithmetic.
•   P, the parity flag − The parity flag represents the number of 1's
in the accumulator register only. If the A register contains odd
number of 1's, then P = 1; and for even number of 1's, P = 0.
• OV, the overflow flag − This flag is set whenever the result of a
signed number operation is too large causing the high-order bit to
overflow into the sign bit. It is used only to detect errors in signed
arithmetic operations.
