Program: B. Tech Integrated (Information Technology)   Semester: V
Course : Introduction to IT Infrastructure Landscape   Code: 701IT0C005
Teaching Scheme   Evaluation Scheme
Lecture   Practical   Tutorial   Internal Continuous   Term End
(Hours   (Hours per   (Hours   Credit   Assessment (ICA)   Examinations (TEE)
per week)   week)   per week)   (Marks- 50)   (Marks- 100)
2   2   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Introduction to IT Systems.
Course Objective
This course is designed to take students through IT infrastructure landscape as an overview of
different building blocks and their functionalities. It will give students an idea about the different
roles as IT engineers can play in IT infrastructure domain.
Course Outcomes
After completion of the course, student would be able to-
1. Describe IT infrastructure Architecture building blocks and their relevant concepts
2. Study the overview of Database, Network, Storage Systems, cloud-based systems
3. Explain various Roles and responsibilities in IT landscape as IT engineer
Detailed Syllabus
Unit   Description   Duration
1   IT Infrastructure Building Blocks and Concepts   3
Definition of IT infrastructure, IT building blocks: Processes / Information
building block, Applications building block, Infrastructure building blocks.
2   IT Infrastructure Performance Concepts   2
Performance of infrastructure design vs Performance of a running system.
Performance testing, Scalability, Load balancing, Capacity management.
3   Network overview   5
Types of networks, Layers concepts, Different Protocols, Network Topologies,
Switching concepts, IP addressing, Routing, Virtual LAN
Security overview: Firewall, Security basics, Security components, Encryption-
decryption, key encryptions, data security, network security.
Data Centers – Physical Infrastructure and Storage
4   Database overview   5
Database System Applications, Purpose of Database Systems, View of Data,
Database Languages, Data Models, Database Users, Files base vs DBMS
SQL vs NoSQL, Introduction Data mining and data warehouse.
5   Storage overview   5
Storage Overview, What is Storage Networking Technology?, Types of Storage
Systems, Storage Devices and Technologies, RAID Functions, RAID Types,
Archiving Data and data policy, Data storage Techniques, Optical Storage, Solid
State Drives, Introduction to Storage Area Networks, Cloud-based storage
services.

Server Technology, Blade Server, Rack Servers,   Enterprise Server, High

Operating System, Virtualization, Benefits of Virtualization, Types of
virtualization, Hypervisor, Types of Hypervisor, Features of Hypervisors, I/O

7   Cloud computing   3
Deployment and Service models, SAAS, PAAS, IAAS, Introduction to AWS,
MICROSOFT AZURE cloud-based services.
