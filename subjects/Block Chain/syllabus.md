 The course is designed to introduce students to the concepts of Block-chain and its

 The course provides an overview of the structure and mechanism of Block-chain and
the Ethereum ecosystem, how smart contracts are developed using Solidity and how
to deploy a business network using Hyper-ledger Composer
Outcomes:
After completion of the course, students would be able to:
1. Learn how Block-chain and Bitcoin work.
2. Learn programming in the ethereum ecosystem & develop Smart Contracts using
Solidity.
3. Develop application & use cases in Block-chain.
4. Create Block-chain Architecture
