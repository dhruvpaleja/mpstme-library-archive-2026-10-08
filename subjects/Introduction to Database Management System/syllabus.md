Prerequisite: NIL
Course Objective
To impart the knowledge of database concepts and the role of DBMS. Students will learn practical skills in
data modelling, SQL querying, and normalisation while also engaging in hands-on projects and exploring
real-world applications to enhance their critical thinking and problem-solving abilities.
Course Outcomes
After completion of the course, the student will be able to -
1. Understand the basics of data and databases and types of data Models
2. Design ER models to model user requirements effectively.
3. Apply normalisation techniques and convert ER models into relational tables.
4. Construct SQL commands to create and retrieve data from tables.
5. Understand advanced database concepts in MongoDB (NoSQL) and YugaByte (NewSQL).
Detailed Syllabus
Unit   Description   Duration
1.   Introduction to Databases and Types   02
Concept of data, database and DBMS, Advantages of DBMS over file processing,
Data abstraction, data independence, Database Users and Administrators,
Overall Database system structure
2.   Data Modeling   06
Need for Data Modeling, Types of Data Models (Relational Model, Network
Model, Hierarchical Model, Entity Relationship Model)
Entity Relationship Model
Components of the ER Model, Entity Set (Strong & Weak Entity set), Attributes,
Types of Attributes, Relationships (Cardinality, Degree, Participation
Constraints), Symbols for ER diagram, ER Diagrams, Case Studies of ER
Diagrams and Design Process, Enhanced ER features.
3.   Relational Model   10
Tables (Relations), Rows (Tuples), Domains, Attributes, Keys - Super Keys,
Candidate Key, Primary Key, Foreign Key, Data Constraints - Domain
Constraints, Referential Integrity Constraints
Normalisation

Introduction and Datatypes, Database Languages, Data Definition Language

Clause, Aggregate functions), Subquery (IN, ANY, ALL)
5.   Advanced database Concepts   04
Introduction to NOSQL, NoSQL Database types, Comparison of SQL and
NoSQL, Case Discussions of Advanced Databases like MongoDB & YugaByte -
NewSQL (Thinking Beyond SQL & NO SQL), Amazon DB and Cloud DB using
IaaS and PaaS
