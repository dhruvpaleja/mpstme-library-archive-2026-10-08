Pre-requisite: Basic computer knowledge, Data Warehousing and Mining
Course Objective
The objective of the course is to familiarize the students with tools and processes to analyze
datasets using visual representations of the data. The course helps students to visualize the data
in graphs, charts, maps etc., and thereby identify patterns and develop actionable insights that
help one to make better, data-driven decisions.
Course Outcomes
After completion of the course, student would be able to-
1. Demonstrate a working knowledge of data visualization
2. Create visualization charts appropriate for the underlying data
3. Apply modern statistical learning techniques on data visualizations
4. Design and implement interactive links between various objects in a data visualization report
Detailed Syllabus
Unit   Description   Duration
