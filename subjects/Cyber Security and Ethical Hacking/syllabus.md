Objective:
1. This course is an introduction to the field of Cyber Security. This course presents a balance

2. Students will learn about the threats to information and ways to overcome it.
Course Outcomes: After completion of the course, students would be able to
1. Explain the basic concepts of cyber security.
2. Implement mechanisms for access control, cryptography and authentication.
3. Differentiate security mechanisms in programs, web applications and networks.
4. Understand the basic digital forensics and techniques for conducting the forensic
examination on different digital devices.
