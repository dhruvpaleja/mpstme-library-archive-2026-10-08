Pre-requisite: Knowledge of Basic Electronics, Engineering Mathematics III (BTAB03001)

Objectives:
1. To understand the basic theory of process and control systems and system stability.
2. To analyse the system design in fulfilling the performance and stability criterion.
3. To evaluate different stability criteria.

Outcomes:
After the successful completion of this course, the student will be able to
1. Identify the basic functioning and components of feedback control system.
2. Analyse processes of different orders, their dynamic and steady state response in
relation to stability.
3. Compare different stability analysis criteria.
4. Know the working principle and tuning of PID controllers.

Detailed Syllabus:

Unit Description Duration
(Hours)

1 Introduction to feedback control system: 02

Open loop and closed loop systems, servomechanisms, basic structure
of a feedback control system.

2 Dynamic Models and Responses: 06
Dynamic model of an RLC network, impulse response model, transfer
function model, standard test/ disturbance signals and their models,
transfer function model and dynamic response of a second order
electrical system.

3 Control System Components: 08
Basic units of a feedback control system, reduction of system block
diagrams, signal flow graphs, Mason’s gain rule, block diagram
reduction using Mason’s gain rule, servo potentiometer, DC and AC
servomotors, DC and AC servomotors, tacho-generator, stepper motor,
synchros, block diagram model of a typical control system using
simplified sub- system, transfer function blocks.

4 Feedback Control System Characteristics: 08
Stability, sensitivity, disturbance rejection, steady state accuracy,
transient and steady state responses of a second order system. Effect of
additional zeros and pole locations and dominant poles, steady state
error constants, system type numbers and error compensation

5 System Stability analysis 08
System stability bounds, routh stability criterions, relative stability and
range of stability, root locus concept, system characteristic equation,
plotting root loci.
