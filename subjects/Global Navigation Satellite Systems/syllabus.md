Program: MBA Tech. (EXTC)   Semester : VIII
Course :   Global Navigation Satellite Systems   Code : BTET08014
(Departmental Elective - 3)
Teaching Scheme   Evaluation Scheme
Lecture   Practical Tutorial   Internal   Term End Examinations
(Hours   (Hours   (Hours   Continuous   (TEE)

3   2   0   4   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Analog and digital Communication, Satellite Communication,
Electromagnetic Field theory.
Objectives:
1. To understand fundamentals and working of Global Positioning System.
2. To compare various GNSS systems.
3. To understand principle and applications of IRNSS and GAGAN.
4. To study effects of various errors on performance of GPS receivers.
Outcomes:
After successful completion of this course, students will be able to:
1. Analyze the basic concepts and working of GPS.
2. Discuss the significance of technology and working utilized for various GNSS
systems.
3. Relate theoretical concepts to various applications of GNSS.
4. Understand various recent applications of GNSS.
Detailed Syllabus:
Unit Description   Duration
1.   Introduction to GPS
Overview and Basics of NAVSTAR GPS, GPS segments, GPS orbits
and satellite position determination, GPS frequencies, GPS signals   05
structure, GPS codes, Navigation message, NMEA strings, GPS
coordinate frames.
2.   GPS position location principles
Absolute and Differential Positioning, Point positioning, Principles   06
of Position fixing with GPS, Pseudo ranging, Carrier Phase,
Ambiguity, Coordinate system for GPS, Advantages and current
limitations of GPS, GPS applications.

3.   GPS Receivers
GPS receivers, Types of GPS receivers: Navigation receivers,   06
Surveying Receivers and Geodetic Receivers, Structure, components
and operation of GPS receivers, GPS Antennas.
4   GPS Errors and Accuracy
Satellite dependent: Ephemeris errors and orbit perturbations,
Forces on GPS satellites, Effects of orbital bias, Types of satellite
ephemerides, Satellite clock bias, Selective availability.
Receiver dependent: Receiver clock bias, Cycle slip, Selective
availability (SA).   05
Observation medium dependent: Ionospheric errors, Tropospheric
errors.
Station dependent: Multipath, Station coordinates.
Satellite geometry based measures: Geometry dependent (Dilution
of Precision: DOP), User Equivalent Range Error UERE.
5.   Introduction to Global Navigation Satellite system: GNSS
Introduction to various navigation systems: Indian Regional   06
Navigational Satellite system (IRNSS), GPS Aided Geo Augmented
Navigation (GAGAN), Global Navigation Satellite System
GLONASS, COMPASS, GALILEO, BeiDou Navigation Satellite
System (BeiDou) and Quasi Zenith Satellite System (QZSS).
6.   IRNSS
Indian Regional Navigational Satellite system (IRNSS) Architecture,   06
segments, Navigation satellites, Signal characteristics, PRN codes,
Data structure, sub frame structure, applications.
7.   Satellite based Augmentation System: GAGAN
SBAS concepts, SBAS segments, SBAS concept of operation, GPS
Aided Geo Augmented Navigation (GAGAN) overview, system   06
configuration, architecture, GAGAN Segments, applications.
8.   GPS Applications
GPS Application in Surveying and Mapping, Navigation Military,
Location Based Services, Vehicle tracking, Geographical   05
Information System, Remote sensing.
GPS modernization plans, Future of GNSS.
Total   45

2. Experiments covering the following topics:
 Introduction to Global Positioning System (GPS).
 Measurement of signal to noise ratio of satellite signals captured by GPS receiver
from various satellites with varying PRN numbers.
 Using SKY plot window to study Azimuth and Elevation angle of satellites and
determining geographical location of user with respect to GPS receiver location.
 Observing and studying various National Marine Electronics Association
(NMEA) GPS strings.
 Introduction to IRNSS.
