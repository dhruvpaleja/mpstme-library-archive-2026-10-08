Pre-requisite: Digital Logic Design, Microprocessor and Microcontrollers
Course Objective
This course gives the understanding of embedded systems and real-time operating systems that can
help identify and define design problems and challenges of real-time operating systems.
Understanding of this course will help in design of embedded systems applications to process inputs
and gather data in real time to produce desired output.
Course Outcomes
After completion of the course, students will be able to -
1. Explain components of embedded systems and design requirements for various applications
2. Implement embedded system’s communication protocols
3. Describe Real Time Operating Systems (RTOS) and their multitasking
4. Design an embedded system for low power applications with the help of Integrated
Development Environment (IDE).

Pre-requisite: Microprocessor, Microcontroller, Computer Organisation

Objectives:
1. To Provide knowledge in Hardware and Software concepts of Embedded System.
2. To Provide knowledge in interfacing of Embedded system.
3._To Provide knowledge in testing and debugging of Embedded system.

Outcomes:

After successfully completion of this course, students should be able to
1. Design develop and implement real time embedded systems
2. Pursue studies in advanced embedded systems

Detailed Syllabus:
Unit | Description Duration
1. Introduction to Embedded systems: 04

Examples of Embedded Systems, Typical Hardware required for
Embedded Systems and review of concepts of: Gates, Power and
Decoupling, Floating signals, signal loading, Timing diagrams and
memory

Networking of Embedded Systems basic concepts of Controller Area
Network (CAN) Interface in Embedded System

2. Advanced Hardware Fundamentals: 03
Microprocessors, Busses, DMA, Interrupts, UART, programmable
array logic, Watch dog timers, Built-Ins on the Microprocessor,
Memory cache and instruction pipeline

3. Interrupts and the Shared Data Problem: Interrupts: 06
Basics, Saving and restoring and disabling, Understanding and
solving, shared data problems , Characteristics of shared data bugs,
solving the shared data problem, Understanding Atomic and critical
sections, Interrupt latency, Alternatives to disabling interrupts,
Typical C programs for solving shared data problems without
disabling interrupts

Real time operating Systems:

Basic concepts of RTOS, Understanding Task and Task states and

shared data problems

Initialising and reentrancy of Semaphores, Semaphores as signalling
devices, Seamphore problems and variants

06

Operating system Services: Message Queues , Mail boxes an pipes
concepts of Pointers and queues , Timers Functions and various
services, Understanding call back functions and writing typical
programs in C using call back functions. Comparison of various
methods of Inter-task communication. Memory management,
Interrupt routines in RTOS Environment, Understanding and
explanation of the rules that do not apply to task code

06

Basic design using a Real time operating System:

Overview and basic concepts, General operations and principals
relating to Interrupts, selection priority and encapsulation of tasks
creating and destroying of tasks , design of Typical task and
programming in C, Designing a simple typical Embedded system
such as Vending machine, Mobile etc covering software and hardware
aspects.

06

Embedded Software Development tools:

Basic difference in development tools for a normal application and
Embedded System, Host and target machines, Cross assemblers,
Linkers / Locators Address resolution, Locating Program components
properly , initializing data and constant strings . Locator maps and
executing out of Ram, Getting Embedded software into target system |

06

Debugging & Testing Techniques:

Importance of Debugging, Testing on host machine, Basic technique
for testing embedded software , Logic and Programming in C for
designing a interface between hardware independent software and
rest of code, codes in C for, Calling interrupt routines and timer ,
Test scaffold software and its limitations and shortcomings,
Instruction set simulators.

Laboratory Tools: Volt Meter, ohm meter, oscilloscope, Logic
analyser, In circuit Emulators, Monitors
