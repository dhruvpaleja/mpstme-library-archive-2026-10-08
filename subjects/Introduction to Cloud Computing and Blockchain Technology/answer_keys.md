Q6   b. What is cloud virtualization? Explain its working and discuss its benefits.   [10]
CO-
2 ;   Answer:
SO-   Cloud virtualization: Cloud virtualization is the foundational technology of cloud computing, where
2 ;   software creates virtual versions of physical resources like servers, storage, and networks, enabling
them to be shared by multiple users simultaneously.
BL-
2   •   This process, known as abstraction, allows for the efficient use of hardware, leading to
increased flexibility, scalability, cost savings, and on-demand provisioning of computing power
for various applications and services.
How it Works:
1. Abstraction:
•   A special software layer called a hypervisor is used to abstract the physical hardware.
2.Resource Pooling:
•   This software pools the physical resources (like processing power, memory, and storage) from
the underlying hardware.
3. Virtualization:
•   The hypervisor then creates multiple isolated virtual machines (VMs) on top of the single
physical server.
4. Independent Operation:
•   Each VM can run its own operating system and applications, interacting independently while
sharing the resources of the host machine.
Benefits:
 Increased Efficiency: Maximizes the use of physical hardware by allowing multiple virtual
machines to run on a single server, reducing waste.
 Cost Savings: Fewer physical servers are needed, leading to lower hardware costs, reduced
energy consumption, and less maintenance.
 On-Demand Resources: Users can access and allocate computing resources as needed, creating
the illusion of infinite resources.
