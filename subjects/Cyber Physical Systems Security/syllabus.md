- Course as printed: Cyber Physical Systems Security (code 702IT0E030)

````text
Program: B Tech CSE (Cybersecurity)   Semester : VII
Course : Cyber Physical Systems Security   Code: 702IT0E030
Teaching Scheme   Evaluation Scheme
Practical   Tutorial
Lecture   Internal Continuous   Term End
(Hours   (Hours
(Hours per   Credit   Assessment (ICA)   Examinations (TEE)
per   per
week)   (Marks - 50)   (Marks - 100)
week)   week)
2   2   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Fundamental Knowledge of Cybersecurity
Course Objective
This course provides an introduction to security issues relating to various cyber-physical systems
including industrial control systems and critical infrastructure systems.
Course Outcomes
After completion of the course, the student would be able to –
1. Describe what cyber-physical systems are
2. Demonstrate what makes cyber-physical systems hard to secure
3. Analyze various security threats related to CPS and their countermeasures
Detailed Syllabus
Unit   Description   Duration
1.   Cyber Physical Systems (CPS)   3
Introduction, emergence of CPS, CPS applications in various domains, CPS
concepts and principles.
2.   Security and Privacy for Cyber-Physical Systems   4
Security and Privacy objectives for CPS, CPS attacks and threat, CPS attack
modelling and detection, CPS architecture and attacks, attack mitigation
strategy.
3.   Key Management in CPSs   3
Introduction, Key Management Security Goals and Threat Model, CPS Key
Management Design Principles, CPS Key Management, CPS Key Management
Challenges and Open Research Issues.
4.   Industrial Control Systems   5
Overview, ICS architecture, The SANS ICS410 Reference Model, The Purdue
Model for ICS, attacks on ICS and mitigation techniques
5.   Software Defined Networks   5
Introduction, Security for Software-Defined Networks, Privacy Leakages for
Software-Defined Networks.
6.   CPS security and Privacy Issues case study   10
Security and Privacy issues related to IoT, Smart Home and buildings, Smart
Grid Network, Modern Vehicle, Wearable Computing & BYOD, Mobile
HealthCare.
Total   30
