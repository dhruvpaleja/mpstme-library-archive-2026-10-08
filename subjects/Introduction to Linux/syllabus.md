Pre-requisite: Nil
Course Objective
The objective of this course is to make the students understand the concept behind Free and Open
Source Software, its use, importance and impact in the society.
Course Outcomes
After completion of the course, the student will be able to -
1. Understand the Open Source Methodology and its Ecosystem
2. Demonstrate various Basic Commands & Advance Commands of Linux
3. Demonstrate Basic Shell Scripting (Shell Scripts/C programs)
Detailed Syllabus:
Unit   Description   Duration
1.   FOSS Philosophy   03
Introduction to Free and Open Source Software, History of Open Source
Software, OSI & FSF, FOSS Advantages/Disadvantages, Economic impact of
FOSS, Social impact of FOSS, FOSS in Governments Sectors, FOSS in
Education, Software Licensing.
2.   Introduction to Linux   02
Linux Architecture, Features of Linux, Linux File System, Linux
Distributions, Linux Console, Linux Desktop, Startup and Shutdown Process,
Types of Desktop: X-Windows, KDE, GNOME.
3.   Linux Commands   04
General Purpose Utilities, File Handling Utilities, Process Management,
Simple Filters, and Filters using Regular Expressions-grep.
4.   Filter Command & Editors   02
Using Advanced Filters: AWK, Working with various editors: sed, vi/vim
Editor, Gedit, Nano, GNU Emacs, Kwrite, gVim, Bluefish.
5.   Shell Scripting Basics   04
Basic Script Building: Using multiple commands, creating script files,
displaying messages, using variables, redirecting input/output, pipes
performing math, exiting script, Working with if else, for, while, until loops,
executing shell scripts and C programs.
Total   15
Text Books
1. Sumithbha Das, Unix Concepts & Applications, 4th Edition, Tata McGraw Hill, 2017.
2. Reference Paper: Kenneth Wong, Phet Sayo, Free/Open Source Software: A General Introduction,
published in United Nations Digital Library, ISBN/ISSN: 9833094007, 2006.

3. The Linux Foundation: http://www.linuxfoundation.org/
