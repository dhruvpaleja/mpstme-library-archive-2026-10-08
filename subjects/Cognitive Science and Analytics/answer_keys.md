Conceptual Working   (2M)

1. Nominal Scale (2 Marks)
•   Definition:
Nominal scale classifies data into distinct categories without any order or
ranking.
•   Characteristics:
o No logical order
o Only labeling/classification
o No mathematical operations possible
• Examples:
o Gender (Male/Female)
o Blood group (A, B, AB, O)

• Explanation:
Numbers assigned (e.g., 1 = Male, 2 = Female) are just labels and have no

2. Ordinal Scale (2 Marks)
•   Definition:
Ordinal scale represents data with ordered categories, but differences
between values are not uniform.
•   Characteristics:
o Ranking is possible
o No equal intervals between ranks
o Limited arithmetic operations
• Examples:
o Customer satisfaction (Poor, Average, Good, Excellent)
o Class ranks (1st, 2nd, 3rd)
• Explanation:
We know the order, but not the exact difference between ranks.
3. Interval Scale (2.5 Marks)
•   Definition:
Interval scale has ordered values with equal intervals, but no true zero
point.
•   Characteristics:
o Equal spacing between values
o Addition and subtraction possible
o No meaningful ratio comparisons
• Examples:
o Temperature in Celsius or Fahrenheit
o Calendar years
• Explanation:
Difference between 20°C and 30°C is same as between 30°C and 40°C, but
0°C does not mean absence of temperature.
4. Ratio Scale (2.5 Marks)

•   Definition:
Ratio scale has all properties of interval scale plus a true zero point, allowing
meaningful ratios.
•   Characteristics:
o Equal intervals
o Absolute zero exists
o All arithmetic operations possible
• Examples:
o Height, Weight
o Age
o Income
• Explanation:
A person weighing 60 kg is twice as heavy as one weighing 30 kg.
Understanding measurement scales is essential for selecting appropriate statistical

Introduction (1 Mark)
In analytics, statistical inference techniques such as confidence intervals and
hypothesis testing are used to make decisions about a population based on sample
data. They help quantify uncertainty and validate assumptions.
1. Confidence Intervals (CI) (4 Marks)
Definition
A confidence interval is a range of values within which the true population parameter
is expected to lie with a certain level of confidence (e.g., 95%).
Interpretation
• A 95% CI means: if we repeat sampling many times, 95% of intervals will
contain the true mean.
Example
Sample mean = 50, σ = 10, n = 100
→ CI = 50 ± 1.96 × (10/√100)
→ CI = 50 ± 1.96
→ (48.04, 51.96)
2. Hypothesis Testing (4 Marks)
Definition
Hypothesis testing is a statistical method used to test assumptions (hypotheses)
about a population parameter.
Steps Involved
1. Formulate Hypotheses
o Null hypothesis (H₀): No effect
o Alternative hypothesis (H₁): Significant effect
2. Select Significance Level (α)
o Commonly 0.05
3. Choose Test Statistic
********** 19 **********
--- page 20 ---
o   Z-test, t-test, etc.
4. Decision Rule
o Reject H₀ if p-value < α
Example
•   H₀: Mean = 50
• Sample mean = 52
•   If p-value < 0.05 → Reject H₀
Conclude there is a significant difference
3. Relationship Between CI and Hypothesis Testing (0.5 Mark)

(c) Explain principal component analysis (PCA) and its importance in dimensionality reduction.
PCA overview: Principal component analysis is a linear dimensionality reduction technique that transforms
the original features into a new orthogonal coordinate system. The new axes (principal components) are
ordered by the amount of variance in the data they capture. PCA computes eigenvectors and eigenvalues of
the covariance matrix (or performs singular value decomposition on the centered data) and projects data
onto the top-k principal components.
Steps:
1. Center the data (subtract the mean).
2. Compute covariance matrix (or use SVD).
3. Compute eigenvalues/eigenvectors.
4. Sort eigenvectors by eigenvalues descending.
5. Project original data onto top-k eigenvectors.
Why PCA matters:
• Noise reduction: By discarding components with low variance (often noise), PCA yields cleaner
signals for modeling.
• Computational efficiency: Reducing dimensions lowers memory and compute costs for
downstream algorithms.
•   Visualization: PCA to 2–3 components enables visualization of high-dimensional structure.
• Mitigate multicollinearity: PCA produces orthogonal features, helpful for algorithms sensitive to
correlated inputs.

maximizing variance may not be optimal for predictive tasks). Alternatives include kernel PCA and
autoencoders for nonlinear structure.

(a) Define structured and unstructured data with examples. Explain why this distinction is crucial
for selecting appropriate analytical techniques.
Structured data refers to data that is organized in a predefined format or schema, typically stored in
relational databases or spreadsheets. Each element has a specific data type, field, and relationship.
Examples include sales records, transaction logs, or sensor readings stored in SQL tables with attributes
like Customer_ID, Date, Amount, and Product_ID. Such data is easy to query, filter, and aggregate
using structured query languages and statistical techniques.
Unstructured data, on the other hand, lacks a fixed format or schema. It includes text documents,
images, audio, videos, social media posts, and emails. For example, tweets, customer reviews, product
images, and voice commands contain meaningful information but are not organized into tabular form.
Analyzing such data requires natural language processing (NLP), image recognition, or audio signal
processing techniques.
Importance of the distinction:
The differentiation between structured and unstructured data is crucial because it determines how data
should be stored, processed, and analyzed. Structured data supports traditional analytics such as SQL
queries, descriptive statistics, and regression models, while unstructured data requires advanced
analytics like deep learning, NLP, and computer vision. The distinction ensures the right tools and

(b) Explain how the four measurement scales (nominal, ordinal, interval, ratio) influence statistical
techniques.
1. Nominal Scale:
Represents data with categories that have no order or ranking.
Example: Gender (Male, Female, Other), Type of product.
Statistical techniques: Frequency counts, mode, chi-square test, contingency tables.
2. Ordinal Scale:
Represents ordered categories where the relative ranking matters but differences are not
measurable.
Example: Customer satisfaction (Poor, Average, Good, Excellent).
Techniques: Median, rank correlation (Spearman’s rho), non-parametric tests (Mann–Whitney
U).
3. Interval Scale:
Ordered data where the difference between values is meaningful, but there is no true zero.
Example: Temperature in Celsius or Fahrenheit.
Techniques: Mean, standard deviation, correlation, t-tests, ANOVA.
4. Ratio Scale:
Contains all properties of an interval scale but with an absolute zero, allowing meaningful ratios.
Example: Weight, height, income, age.
Techniques: All parametric analyses—regression, correlation, coefficient of variation.
Influence on analytics:
Measurement scales determine the level of permissible mathematical operations and the appropriate
choice of analytical or statistical technique. Using a parametric test on nominal data, for instance, would
violate assumptions, leading to unreliable results.

Interdependence techniques explore relationships among variables without defining any as dependent

(b) When would you choose factor analysis over regression analysis? Justify with an example.
Factor analysis is chosen when the goal is to identify underlying latent factors that explain correlations
among observed variables, rather than to predict a dependent outcome.
Regression analysis, however, is used when there is a specific dependent variable to be explained or
predicted using independent variables.
When to use factor analysis:
• When dealing with many interrelated variables and aiming to reduce dimensionality.
• To uncover hidden constructs such as intelligence, customer satisfaction, or brand perception.
• When there is no explicit dependent variable but the objective is to reveal structure.
Example:
A company surveys customers on 20 satisfaction questions about product quality, service, and pricing.

If instead the company wanted to predict overall satisfaction (a dependent variable) from those 20
variables, regression analysis would be appropriate.

(a) Explain the concept of Named Entity Recognition (NER) and topic modeling in text analytics.
Named Entity Recognition (NER) and topic modeling are two essential techniques in text analytics,
helping convert unstructured textual data into structured, meaningful information.
Named Entity Recognition (NER):
NER is a subtask of Natural Language Processing (NLP) that identifies and classifies specific entities in
text into predefined categories such as person names, organizations, locations, dates, products, and
monetary values.
For example, in the sentence — “Elon Musk founded SpaceX in 2002 in California,” — NER would
extract:
• Person: Elon Musk
• Organization: SpaceX
• Date: 2002
• Location: California
How NER works:
NER models are trained using machine learning or deep learning methods such as Conditional Random
Fields (CRF), Bi-LSTM, and Transformer-based models like BERT. They analyze the syntactic
structure (part-of-speech tags) and context to determine whether a word is an entity and which type it
belongs to.
Applications:
********** 6 **********
--- page 7 ---
• Information extraction from news, legal, and financial documents.
• Enhancing search engines by identifying key entities in queries.
• Automating tagging in CRM and content management systems.
By transforming unstructured text into labeled data, NER improves data organization, discoverability,
and semantic understanding in analytics systems.
Topic Modeling:
Topic modeling is an unsupervised machine learning technique that discovers abstract themes or
“topics” that occur within a collection of documents. It helps summarize and categorize large volumes
of text automatically.
Key methods:
1. Latent Dirichlet Allocation (LDA): Models each document as a mixture of topics and each
topic as a distribution of words.
2. Non-Negative Matrix Factorization (NMF): Factorizes the term-document matrix into latent
topics and term weights.
3. BERTopic: Uses transformer embeddings and clustering for contextual topic discovery in
modern NLP.
Example:
Analyzing thousands of product reviews might reveal topics such as delivery issues, product quality,
pricing, and customer service.
Applications:
•   Social media trend analysis and sentiment grouping.
• Customer feedback mining for business intelligence.
• Research paper or news article categorization.
Comparison with NER:
While NER identifies specific entities in text, topic modeling extracts general themes. Combined, they
provide both micro-level (entities) and macro-level (topics) understanding—essential for deep text
analytics and knowledge discovery.
