- Course as printed: Elements of Project Management (code 702ME0I012)

````text
Program: B Tech programs except B Tech CSBS and B Tech CSE (DS) Semester: V/VI
Course: Elements of Project Management   Code: 702ME0I012
Teaching Scheme   Evaluation Scheme
Lecture   Practical   Tutorial   Internal Continuous   Term End
(Hours   (Hours   (Hours   Credit   Assessment (ICA)   Examinations (TEE)
per week)   per week)   per week)   (Marks - 50)   (Marks- 100)
3   0   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: - NA
Course Objective
This course introduces aspects of project management such as formulation, budgeting,
planning, scheduling and control of projects from initiation to completion.
Course Outcomes
After completion of the course, students will be able to -
1. Interpret the project feasibility and identify the role of project manager
2. Relate the resources and durations using scheduling tools and techniques
3. Plan the costs and risks of projects
4. Apply the tools for monitoring the progress of projects
Detailed Syllabus
Unit   Description   Duration
1.   Introduction to Project Management
Definition, classification of project management in different environments,   08
scope, systems approach, project feasibility, project life cycle, systems
development cycle phases.
2.   Project Organization
Project organization, types of structures, roles of project managers and   05
team, integration in large scale projects.
3.   Project Planning and Scheduling
Planning fundamentals, project master plan, work breakdown structure
and other tools of project planning, work packages, project organization
structure and responsibilities, responsibility matrix, use of Gantt charts,   12
critical path method (CPM) and project evaluation and review technique
(PERT) for scheduling and resource allocation, introduction to software
tools for documentation, scheduling, analysis etc.
4.   Cost Estimating and Budgeting
Cost estimating process, elements of budgeting, project cost accounting and   06
management information systems, cost schedules and forecasts.
5.   Project Risk Management
Risk concepts and identification, risk response planning, risk management
09
methods, information monitoring, control process, cost accounting systems
for project control, performance analysis.
````
