b.   A university website displays information about admissions, departments,
events, and research all on a single page, causing confusion among users.
Explain how applying Gestalt principles such as proximity, similarity,
closure, and continuity can help organize the layout to improve clarity and
user experience.
Ans-
The university website displays too much information on a single page,
causing confusion. Gestalt principles can help organize the content:
Proximity – Group related information together:
Admissions-related content in one section
Departments and programs in another
Events and research updates in separate sections
This reduces visual clutter and helps users quickly find what they need.
Similarity – Use consistent styles for similar content:
CO-1;   Similar font, color, or icon style for all department listings
SO-2;   Consistent design for all events   10
This creates a visual pattern that users can easily follow.
BL-4   Closure – Help users perceive complete sections even with partial cues:
Use boxes, cards, or section borders so users mentally group content
Example: partially displayed department info still appears as a coherent
unit.
Continuity – Guide users’ eyes smoothly through content:
Arrange sections in a logical flow (e.g., Admissions → Departments →
Events → Research)
Use visual lines or arrows to indicate progression
Helps users understand the structure without confusion.
Result: Applying these principles organizes the layout, improves
readability, and enhances the overall user experience by making the
website intuitive and less overwhelming.

Explanation of each principle (4), application to layout (4), improvement in
clarity (2)
