ANSWER KEYWORDS
1. Key components of DevOps
a. Continuous Integration (CI)
i. Concept: Developers frequently merge code into a shared repository.
ii. Tools: Jenkins, GitLab CI, CircleCI
iii. Benefits: Detect bugs early, faster feedback.
iv. Example: Every code commit triggers automated build & unit tests.
b. Configuration Management
i. Concept: Managing infrastructure and system setup consistently across environments.
ii. Tools: Ansible, Puppet, Chef
iii. Benefits: Eliminates “it works on my machine” issue, ensures consistency.
iv. Example: Automatically provisioning servers with same OS, libraries, and settings.
c. Continuous Deployment (CD)
i. Concept: Automated release of code to production after passing tests.
ii. Tools: Spinnaker, ArgoCD, GitLab
iii. Benefits: Faster time-to-market, reduced manual errors.
iv. Example: After successful testing, app version is auto-deployed to cloud.
d. Automated Monitoring
i. Concept: Real-time tracking of system performance, logs, and user experience.
ii. Tools: Prometheus, Grafana, ELK Stack, Datadog
iii. Benefits: Detect issues before customers notice, ensure reliability.
iv. Example: Alerts sent when CPU usage > 80% or response time spikes.

ANSWER KEYWORDS
1. Life-cycle of IT project management.
a. Initiation – Define objectives, scope, stakeholders, feasibility, and obtain approvals.
b. Planning – Build detailed roadmaps: tasks, timelines, budgets, resource plans, risk assessments,
communications.
c. Execution – Teams carry out development, testing, deployment; project manager coordinates
tasks and resources.
d. Monitoring & Controlling – Continuously track scope, schedule, costs, risks, and performance;
adjust as needed .
e. Closure – Finalize deliverables, document lessons learned, release resources, formal sign-off
2. What is the Critical Path Method (CPM)? What are the basic steps to follow in Critical Path Method
(CPM) methodology?
a. CPM is a project planning method that focuses on identifying tasks that are dependent on other
tasks for their timely completion.
b.   It helps determine the best way to execute a project, set a realistic deadline, and track progress.
c. CPM can be done either manually or with computer software.
d. The PM first lists each activity, the order it must be completed, and how long it is expected to
take, and then diagrams the process.
e. CPM is used in most industries that undertake highly complex projects.
f. CPM steps
i. List each activity
ii. Determine the order
iii. Predict time per task – mostly by experience
iv. Draw a diagram
v. Identify the critical path – path with the longest duration
vi. Monitor progress and modify if required
3. Cost control steps
a. Establish Cost Baseline
i. Create a budget based on the Work Breakdown Structure (WBS).
ii. Break costs into categories (labor, materials, equipment, overhead).
b. Monitor Costs
i. Compare Actual Costs (AC) with the budget.
ii. Identify cost overruns early.

d. Take Corrective Action
i. Reduce unnecessary expenses, adjust schedules, or reallocate resources.

4. Type of risks
a. Technical Risks – Technology failures, design errors.
b. Financial Risks – Budget overruns, currency fluctuations.
c. Schedule Risks – Delays, resource unavailability.
d. Operational Risks – Inefficient processes, team issues.
e. External Risks – Regulatory changes, natural disasters, market changes.
5. Project control concept and objectives
a. The process of monitoring, measuring, and regulating project performance to ensure it stays on
track with scope, schedule, cost, and quality objectives.
b. Objectives
i. Detect deviations from plan.
ii. Take corrective/preventive actions.
iii. Ensure project success within constraints.
6. Challenges in the Agile methodology
a. Difficult for large, distributed teams.
b. Requires cultural change & strong collaboration.
c. Less documentation may affect long-term maintenance.
d. Customer availability & involvement is crucial.
7. Explain the Scrum methodology. Describe the best practices of Scrum.
a. Framework within Agile.
b. Uses time-boxed sprints (2–4 weeks), with defined roles (Product Owner, Scrum Master, Team).
c. Focus: Delivering small increments of working product frequently.
d. Scrum = one of the most popular implementations of Agile.
e. Best practices
i. Sprint Planning
ii. Collaboration
iii. Transparency
iv. Sprint Review
v. Retrospective
vi. Quality Focus
vii. Adaptation
