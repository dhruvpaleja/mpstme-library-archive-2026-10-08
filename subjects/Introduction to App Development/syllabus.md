3   0   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Programming for Problem Solving
Objectives:
This course aims to understand Mobile Application Development as a process by which
application software would be developed for low-power handheld devices, such as mobile
devices.
Outcomes:
After completion of the course, students would be able to:
1. Demonstrate the capability to use a range of software tools in support of the
development of a software application.
2. Apply Application Design for a given scenario with graphical user interface concepts.
3. Understand the code necessary to create several simple applications to demonstrate
capabilities on emulator/hand-held device.
4. Design applications with ability to connect to backend database or external files.
Detailed Syllabus: (Per session plan)
Unit   Description   Duration
1   Configuration of Development Platform: Starting an Android   1
Application project: Installing Android Studio and Java, Installing the
Android Development Kit.
2   Getting started: Getting acquainted with Android Studio IDE and   12
Simulator for application development, Building your first app (one
activity, multiple activities), testing the app and using the Android
Support Library, Layouts and resources for UI, Text and scrolling views,
Activities and intents,
3   User Experience: Buttons and clickable images, UI controls, input   12
controls, menus and pickers, user navigation, Recycler View, drawables,
styles and themes, Material Design, Resources for adaptive layouts, UI
Testing.
4   Working in the background: AsyncTask and AsyncTaskLoader, Internet   10
connection, Broadcasts, Services, Notifications, Alarms, Efficient data
transfer.
5   Saving User Data: Data storage, shared preferences, App settings, SQLite   10
primer, Room, LiveData, and ViewModel.
