Prerequisite: Basic Knowledge of Computer Network, Operating Systems and programming
Course Objective
This course is an introduction to the field of cyber forensics. This course introduces various aspects

3. Describe various professional, ethical and legal issues related to cyber forensics

Unit   Description   Duration

cyber forensics, forensic process, types of investigations, digital evidence,

Response

whole disk encryption, Windows registry, file structure of ext4.

malware analysis
4   Network Forensics   4
