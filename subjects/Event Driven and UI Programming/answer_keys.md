a. Characteristics of Graphical and Web User Interfaces (5 Marks)
Graphical User Interface (GUI):
•   Definition: GUI allows users to interact with applications through graphical elements like
windows, buttons, icons, and menus.

c. Advantages and Disadvantages of SDI and MDI (5 Marks)
Single Document Interface (SDI):
•   Definition: SDI allows only one document per window.
• Advantages:
o Simple to implement and use.
o Uses fewer system resources.
o Suitable for lightweight applications.
• Disadvantages:
o   Difficult to manage multiple documents.
o Each document opens in a separate window, increasing clutter.
• Examples: Notepad, Calculator.
Multiple Document Interface (MDI):
•   Definition: MDI allows multiple child windows within a single parent window.
• Advantages:
o Efficient for handling multiple documents.
o Child windows stay within the main application.
o Easy to switch between documents.
• Disadvantages:
o More complex to develop.
o Requires more memory.
• Examples: Microsoft Word, Adobe Photoshop.

Q.5 (20 Marks)
a. ODBC Components, Features, Advantages, and Disadvantages (10 Marks)
• ODBC (Open Database Connectivity) is a standard API for connecting applications to various
databases.
• Components of ODBC:
1. Driver Manager: Manages communication between application and drivers.
2. Driver: Translates SQL queries into DBMS-specific commands.
3. Data Source Name (DSN): Stores database connection information.
4. Application: The software that makes database queries.
• Advantages:
1. Provides a universal interface for different databases.
2. Reduces dependency on specific database vendors.
3. Supports multiple platforms.
• Disadvantages:
1. Slightly slower due to the abstraction layer.
2. Requires proper configuration for each DSN.

a. Role of human characteristics in UI design & Business functions in UI design (10 Marks)
1. Human Characteristics in UI Design:
• Cognitive Load: The UI should reduce cognitive stress by keeping design simple and intuitive.
• Perception: Users perceive information differently, so visual hierarchy should be considered.
• Memory Constraints: Minimize reliance on user memory by providing hints, tooltips, and clear
navigation.
• Learning Curve: Design should be user-friendly with self-explanatory features to shorten the
learning curve.
• Error Tolerance: The UI should provide error handling, undo options, and informative feedback
messages.
2. Business Functions in UI Design:
•   Efficiency & Productivity: UI should improve task completion speed and user efficiency.
•   Scalability: UI should support business growth and new features without drastic changes.
• Security & Compliance: UI should adhere to security policies, data privacy regulations, and
authentication mechanisms.
•   Accessibility: UI should be inclusive, supporting various user needs (e.g., colorblind-friendly
themes, voice assistance).
• Branding: UI should maintain consistency with company branding (logos, color schemes,
typography).
