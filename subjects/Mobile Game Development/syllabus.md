Pre-requisite: Basic programming constructs
Objectives:
This course aims to develop student’s skill to identify, build and evaluate graphics, audio,
user interfaces and development tools required to create 2D and 3D game applications.
Outcomes:
After completion of the course, students would be able to:
1. Identify and evaluate development software for building game application.
2. Author a game application that demonstrates 2D graphics.
3. Author a game application that demonstrates 3D graphics.
Detailed Syllabus:
Unit   Description   Duration
1   Basics of Unity: Exploring Unity IDE (Project, Hierarchy, Toolbar, Scene,   06
Game, Animation Views), Basic Design Theory, Brainstorming,
Researching other Games, Prototyping, Planning with Outline and
Documentation.
2   Assembling the Game Assets: Terrains, Importing Assets, Creating   03
characters.
3   Interactivity in Unity: Scripting (Variables, Operators, Conditionals,   09
Loops, Functions), Polishing (Lighting and Shadows, Particle Systems,
Audio), Designing the game’s GUI, Triggers and Collisions.
4   Building 2D and 3D Games: Game Design, Architecture, Importing   10
Assets, Input, Preparing the Scene, Building Traps and Objectives,
Polishing the game, Particle effects, Menu, Audio, Animation.
5 AR with Unity: Introduction to AR, Difference between AR and VR,   02
Fundamentals of ARCode (AR SDK for Android).
Total   30
