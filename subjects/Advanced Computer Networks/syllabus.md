Prerequisite: Computer Networks
Course Objective
The objective of this course is to familiarize students with the working of internetworks. This course
focus on top-down approach, the Internet and a modern treatment of computer networking, its
attention to both principles and practice, and its accessible style and approach toward learning
about computer networking.
Course Outcomes
After completion of the course, the student will be able to -
1. Describe medium access layer protocols
2. Design IP addressing scheme, analyze packet forwarding, and compare different routing
protocols
3. Compare and analyze transport protocols and other key protocols essential for networking
4. Explain various multimedia protocols, internet security concepts and future networks
Detailed Syllabus
Unit   Description   Duration
1.   Medium access layer   03
Channel allocation problem, hidden node and exposed node problem FDM,
TDM, CDMA, MACA.
2.   Internet protocol   05
IPv4, compare IPv4 and IPv6, IPv6 - (address, special address, transition from
IPv4 to IPv6; subnetting classless addressing).
3.   Network Layer   06
Routing tables and forwarding, Routing protocols - Open Shortest Path First
and Border Gateway Protocol, DHCP, Mobile IP, AODV.
4.   Transport layer   06
Transmission Control Protocol - Reno, SCTP, I-TCP, Snoop TCP and Mobile
TCP.
5.   Multimedia in the internet   03
SIP, QoS (flow classes, flow control to improve QoS - FIFO, Priority and WFQ).
6.   Network security   05
Introduction to Internet security - application layer security, transport layer
security (SSL and TLS), IPSec, VPN, Firewall, WPA2, WPA3.
7.   Introduction to Internet of Things and applications, software defined   02
networks and 5G.
Total   30
