week)   week)   week)   (Marks- 50)   (Marks- 100)
2   2   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Fundamental Knowledge of Cybersecurity and software engineering
Course Objective
DevSecOps automatically bakes in security at every phase of the software development lifecycle,
enabling development of secure software at the speed of Agile and DevOps. It is an extension of
standard DevOps practices. It integrates application and infrastructure security seamlessly into
Agile and DevOps processes and tools. It addresses security issues as they emerge, when they're
easier, faster, and less expensive to fix. The primary goal of this course is to create a theory and
practice mix that emphasizes on the core concepts of DevSecOps, Docker containers and
Kubernetes clustering from a security, monitoring, and administration perspective.
Course Outcomes
After successful completion of the course, student would be able to -
1. Explain the need for DevOps and DevSecOps
2. Use various DevSecOps Tools
3. Implement DevSecOps using docker and kubernetes
Detailed Syllabus
Unit   Description   Duration
1.   DevOps   6
Software Development Life Cycle, Agile and Scrum Methodology, need for
DevOps and its advantages, DevOps principles and practices, CAMS
(Culture, Automation, Measurement and Sharing), DevOps life cycle, 7C’s of
DevOps lifecycle for business agility.
2.   DevSecOps   8
Need for DevSecOps, DevSecOps lifecycle, DevSecOps Methodologies,
Continuous Integration and Continuous Delivery.
3.   DevSecOps Tools   5
Vagrant, Git, Jenkins, and tools related to Static Analysis Security Testing
(SAST), Dynamic Analysis Security Testing (DAST), Dependency analysis,
Infrastructure as Code security, Secrets management, Vulnerability
assessment and management, and Alerts and monitoring
5.   Docker and Kubernetes Security   5
Principles and best practices, auditing and analysing vulnerabilities and
docker and kubernetes, monitoring of docker and kubernetes.
Total   30
