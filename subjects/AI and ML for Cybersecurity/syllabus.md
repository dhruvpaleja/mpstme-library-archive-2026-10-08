Pre-requisite: Engineering Mathematics – III and IV
Course Objective
This course is an introduction to AI and ML working principles and theory associated with the
algorithm implications. Secondly it connects different techniques of machine learning applications
in context of cybersecurity.
Course Outcomes
After completion of the course, the student will be able to -
1. Solve problems using various Artificial Intelligence and machine learning techniques
2. Design applications using AL and ML techniques
3. Describe applications of AI and ML to cybersecurity problems
Detailed Syllabus
Unit   Description   Duration
1.   Introduction   03
Overview of AI as super set of ML and Deep learning. Type of AI: Weak AI
vs. Strong AI, Narrow AI vs. General AI, Superintelligence, what is machine
learning? Types of ML: Supervised Vs. Unsupervised, how machine learning
can solve specific problem? Application based example in context of cyber
security.
2.   Feature Engineering   03
Types of data and its sources, Data quality, Feature creation. Data
Transformations, Introduction to Dimension reduction like PCA (Principal
Component analysis).
3.   Supervised Learning   04
Classification vs Regression, Linear and Polynomial Regression, Linear
Models: Regression, Ridge, Lasso regularization, Model building with
suitable application, Data pre-processing, Data visualization, model training,
model evaluation.
4.   Classification   04
Logistic, Linear SVM, Naive Bayes classifier; Decision Trees, Multi-class
classification, Model building with suitable application, Data pre-processing,
Data visualization, model training, model evaluation.
5.   Unsupervised learning   03
Clustering -- k-means, Agglomerative clustering, Density Based clustering
(DBSCAN), Comparison of the clustering algorithms.
