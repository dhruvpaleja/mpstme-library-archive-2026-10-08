Pre-requisite: Physics and Mathematics
Course Objective
The course develops an understanding of the necessary software and hardware components of
virtual and augmented reality setup with compatibilities. The students learn to use the tools,
interfacing details and architecture requirements with the final goal of being able to create content
for virtual and augmented reality.
Course Outcomes
After completion of the course, students will be able to -
1. Explain the integration of software and hardware components
2. Select the correct tools for solving problems in practice
3. Develop the basic framework of the algorithm to aid the process of content creation
4. Analyze the existing solutions for computational requirements
5. Synthesize solutions to problems of practical importance for efficiency and performance
