Pre-requisite: Embedded Systems, Data Structures and Operating Systems
Course Objective
This course imparts in-depth knowledge about the need, terminologies and methodologies used
in software protection. Also plan and design software solutions to security problems using
various paradigms.
Course Outcomes
After completion of the course, students will be able to -
1. Develop testing strategies for protected software applications
2. Develop software solutions to security problems using various paradigms
3. Model the secure software systems using SDLC.
Detailed Syllabus
Unit   Description   Duration
1   Introduction to software protection
What, why, how, Setting up software analysis lab, state-of-the-art tools,   06
protocol for handling potentially malicious programs, legal issues,
Offensive and defensive strategies - offense – motivation, methods of attacking
software protection.
2   Defense
Methods for hiding information, purpose, algorithms in software,
Program Analysis
10

3   Secure software architecture and design
Software security practices for architecture and design: architectural risk   12
analysis, Software security knowledge for architecture and design: security
principles, security guidelines, and attack pattens, secure design through
threat modeling.
4   Writing secure software code
Secure coding techniques, secure programming: data validation, secure   12
programming using cryptography, creating software security programs
5   Secure Coding and Testing   05
Code analysis- source code review, coding practices, static analysis, software
security testing, security testing consideration through SDLC
Total   45
