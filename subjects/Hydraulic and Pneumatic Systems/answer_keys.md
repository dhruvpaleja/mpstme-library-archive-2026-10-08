•   In an electrohydraulic system, logic functions like NOR (Not OR) can be
implemented using electrical switches and hydraulic valves. The NOR logic
function states that the output is ON (active) only when both inputs are OFF.
• A NOR gate gives an output of 1 (ON) only when all inputs are 0 (OFF).
Mathematically, the NOR function is:
Y=A+B
Where: A and B are inputs. Y is the output. The output is ON only if both A and B are
OFF.
Electrical Section:
• Two normally open push buttons (A & B) connected in parallel to control
the solenoids.
• A relay coil is used to deactivate the hydraulic system when either switch is
pressed.
Hydraulic Section:
• A 4/2 or 4/3 directional control valve (DCV) is spring-loaded to its default
position when solenoids are de-energized.
• The hydraulic cylinder extends or retracts when both inputs are OFF.

c. Define Pascal's law and provide an explanation of its principles.   [4]
"In a confined fluid at rest, any change in pressure applied to one part of the fluid is
transmitted undiminished to all portions of the fluid and to the walls of   its
container."   [2 Marks]
Pressure Transmission:
• When force is applied to a fluid in an enclosed system, the pressure is
distributed equally in all directions.
• Mathematical Expression:
•   Pressure (P) is given by: P =
FAFA
o P = Pressure (Pa)

b. Describe the ladder logic diagram used for controlling a two-cylinder hydraulic system. [10]
Explain the working principle, key components, and sequence of operations involved in the
control process with an example.
A ladder logic diagram is commonly used in PLC programming to automate hydraulic
systems. In a two-cylinder hydraulic system, the ladder logic program ensures the correct
sequencing of cylinder operations, maintaining synchronization and safety.
1. Key Components of the System
The two-cylinder hydraulic system consists of the following components:
1. Hydraulic Cylinders (A and B): Actuators that extend and retract to perform
work.
2. Directional Control Valves (DCV): Control the flow of hydraulic fluid to
the cylinders.
3. Solenoid Actuators (Y1, Y2, Y3, Y4):
4. Limit Switches (LS):
5. PLC (Programmable Logic Controller): Executes the ladder logic program
based on input signals from limit switches.
6. Start/Stop Push Buttons: Used to initiate or halt the sequence.   [5
Marks]
Working Principle
The ladder logic is designed to control the sequence of operations in which the two
cylinders extend and retract in a specific order. A sequential control system is used,
where one operation triggers the next.
Typical Sequence of Operation:
1. Press Start Button → Cylinder A extends (Solenoid Y1 energized).
2. Cylinder A fully extends (LS1 activated) → Cylinder B extends (Solenoid
Y3 energized).
3. Cylinder B fully extends (LS3 activated) → Cylinder B retracts (Solenoid
Y4 energized).
4. Cylinder B fully retracts (LS4 activated) → Cylinder A retracts (Solenoid
Y2 energized).
5. Cylinder A fully retracts (LS2 activated) → Cycle resets, ready for the
next start.   [5
Marks]

b. Explain the function, types, and applications of check valves and flow control valves in [10]
hydraulic circuits. Discuss their significance in system performance and provide relevant
examples.
1. Check Valves in Hydraulic Circuits
Function:
A check valve allows fluid flow in only one direction and prevents backflow. It is essential
for maintaining pressure, preventing damage, and ensuring unidirectional operation in
hydraulic systems.
Types of Check Valves:
1. Ball Check Valve – Uses a ball to block reverse flow.
2. Poppet Check Valve – Uses a conical poppet for sealing.
3. Swing Check Valve – A hinged flap opens with flow and closes under
backpressure.
4. Pilot-Operated Check Valve – Opens under controlled conditions using
external pilot pressure.
Applications:
•   Hydraulic lifting systems: Prevents load drop by stopping reverse flow.
• Pumps: Prevents backflow when the pump is off.
•   Directional control circuits: Ensures correct actuator movement.
Example:
A pilot-operated check valve is used in a hydraulic press to hold pressure when the pump is
stopped, ensuring the press remains in position.   [5 Marks]
2. Flow Control Valves in Hydraulic Circuits
Function:
A flow control valve regulates the rate of fluid flow, controlling actuator speed and ensuring
stable system performance.
Types of Flow Control Valves:
1. Fixed Orifice Valve – Restricts flow using a fixed opening.
2. Adjustable Flow Control Valve – Allows flow adjustment using a variable
orifice.
3. Pressure-Compensated Flow Control Valve – Maintains constant flow
regardless of pressure variations.
4. Needle Valve – Provides precise flow control using a tapered needle
mechanism.
Applications:
•   Cylinder speed control: Regulates actuator extension/retraction speed.
•   Meter-in and Meter-out circuits: Controls fluid entry and exit for smooth
motion.
•   Hydraulic motors: Ensures steady rotational speed.
Example:
A pressure-compensated flow control valve is used in a hydraulic conveyor system to
maintain a constant belt speed regardless of load variations.   [5 Marks]
