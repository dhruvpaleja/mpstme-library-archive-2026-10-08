Q1 (a) Differentiate between Machine and Structure [05 Marks]
(Machine) – 1 Mark
A machine is a combination of resistant bodies with relative motion used to transmit or
modify energy.
(Structure) – 1 Mark
A structure is an arrangement of members with no relative motion, used to support
loads.
Differences – 3 Marks
• Machine has motion; structure has no motion.
• Machine transmits energy; structure only resists forces.
• Example: Engine (machine), Bridge (structure).
