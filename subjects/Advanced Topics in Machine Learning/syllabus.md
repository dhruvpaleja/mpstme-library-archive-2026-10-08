Prerequisite: Basics of machine learning and deep learning
Course Objective
The course on Advanced Topics in Machine Learning aims to provide students with a deep
understanding of contemporary techniques and methodologies. This course focuses on the recent
advances in machine learning like few-shot learning, autoencoders, Generative Adversarial
Networks (GAN), transformer models. Finally, by delving into graph neural networks, students will
learn to handle and analyze graph-structured data effectively. Overall, the course integrates theory
with hands-on practice to prepare students for advanced challenges in machine learning.
Course Outcomes
After completion of the course, students will be able to -
1. Explain and use meta-learning techniques for different applications
2. Apply concepts of Generative Adversarial Networks to real-world applications
3. Describe and use transformer architecture for sequence to sequence applications
4. Identify and analyze the use of graph neural networks for machine learning models
