Pre-requisite: Android App Development
Course Objective
The aim of the course is to provide students with the tools and technologies to build, deploy, test, run,
and manage full stack applications. It will empower students to deal with both the Frontend (client-
side) and Backend (server-side) of a tech product. It will educate students to position them as full stack
developers, proficient in several technologies enabling them to develop robust tech products, and thus
play a major role in decision making for the organization.
Course Outcomes
After completion of the course, students will be able to -
1. Describe modern   front‑end   technologies by   outlining   advanced HTML/CSS,
Bootstrap /Tailwind utilities, and JavaScript ES6+ features with async patterns.
2. (L2 – Understanding)
3. Apply Python and Django—covering models, views, templates, and REST APIs—to construct
functional back‑end services and integrate machine‑learning models. (L3 – Applying)
4. Design data‑driven applications that use PostgreSQL and MongoDB, and deploy them on
cloud IaaS platforms such as AWS S3 or DigitalOcean. (L4 – Analyzing)
5. Develop interactive single‑page applications in React JS by implementing JSX, hooks, the
Context API, and secure API connectivity. (L3 – Applying)
6. Implement end‑to‑end DevOps practices by containerizing full‑stack projects with Docker
and automating their deployment to solve real‑world problems. (L5 – Evaluating)
