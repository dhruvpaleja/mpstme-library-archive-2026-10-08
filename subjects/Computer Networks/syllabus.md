Course Objective
This course provides the fundamental knowledge of computer networks through understanding each
layer of computer network architecture, and transmission systems to network applications. It also
focuses on congestion control techniques, protocols, and application layer functions.
Course Outcomes
After completion of the course, students will be able to -
1. Identify fundamental concepts of computer networks, network topologies, and OSI & TCP/IP
models. (L3- Applying)
2. Explain error detection and correction techniques along with multiple access protocols used in
the data link layer. (L2- Understanding)
3. Classify IPv4 & IPv6 addressing, subnetting, and routing algorithms for efficient network
design. (L4- Analyzing)
4. Compare transport layer protocols such as TCP and UDP, including congestion control
mechanisms. (L4- Analyzing)
5. Demonstrate the functionalities of application layer protocols such as HTTP, DNS, FTP, and
SMTP for network communication. (L2-Understanding)

This course aims to provide fundamental knowledge of computer networks by exploring network
architectures, classifications, and key models such as OSI and TCP/IP. It covers network layer

layer functionalities. Additionally, the course introduces emerging network technologies and network
security fundamentals.

After completion of the course, the students will be able to -
1.Explain the fundamental concepts of Computer Networks. (K2)
2.Analyze and Implement Data Link Layer Protocols to ensure reliable transmission. (K4)
3.Apply and evaluate network layer functions and routing algorithms (K3)
4.Describe and differentiate various Transport and Application Layer Mechanisms (K2)

This course provides the fundamental knowledge of computer networks through understanding each

3. Apply network layer addressing and routing techniques to different network topologies
4. Analyze the different protocols of the layered architecture of computer networks
