Course Objective
The course is designed to provide basic knowledge of Python programming and how to design
and program Python applications.
Course Outcomes
After successful completion of this course, students will be able to -
1. Recognize various data structures and apply them in solving computational problems.
2. Understand and apply different file handling operations
3. Apply core python and object-oriented python concepts to build real world applications.
4. Using regular expressions to search for patterns in strings and files.
Detailed Syllabus
Unit   Description   Duration
1   Introduction, Variables, and Data Types   3
History, Features, Installation and Execution, Syntax and Semantics,
comments, imports, indentation, variables, Input and Output, Basic data types
and Operators.
2   Python Data Structures   3
Strings, Compound data types-Lists, Dictionaries, Tuples, Sets, Slicing,
properties operations and methods
3   Control Structures   6
Conditional blocks using if, else and elif, for loop, for loop using Ranges,
while loop, loop manipulation using Pass, Continue, Break, Nested loops,
List and Dictionary comprehension, NumPy to create one-dimensional and
two-dimensional arrays, Pandas using dataframes.
4   Functions, Modules and Packages   6
Defining and calling functions, return, scope, function arguments, Global
variables, Default arguments, recursive functions; Built-in functions:
Lambda, Map, Filter, Reduce, Zip, Enumerate, Modules, Packages
5   Files and Exception Handling   4
File Input and Output read/write operations, open, close, with, seek, tell,
manipulating files and directories
Exception, Types of errors, handling an exception, try, expect, else, try-
finally clause, Argument of an exception, Raising an Exception
6   Classes and Objects   5
Class definition, object creation, class variables and methods, accessing class
attributes, self, __init__, inheritance, overriding super class
