(Cybersecurity), BTI Computer Engineering

Teaching Scheme   Evaluation Scheme

week)   per week)   (Marks- 50)   (Marks- 100)

2   2   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Cybersecurity Fundamentals
Course Objective
Mobile devices like smartphones have become are indispensable part of our lives. This course
discusses various threats faced by mobile devices and their countermeasures. This course also
provides comprehensive introduction to android and iOS.
Course Outcomes
After completion of the course, the student will be able to -
1. Describe various threats faced by mobile devices and suggest their counter measures
2. Perform forensics operations on mobile devices
3. Write mobile forensic analysis report
Detailed Syllabus
Unit   Description   Duration
1.   Introduction   05
Mobile communication in brief, cellular coverage maps and hand-off,
evolution of mobile networks (GSM, CDMA, 3G, 4G and 5G networks)
2.   Security Threats   05
Threats to wireless and mobile devices (Data Theft Threats, Device Control
Threats, System Access Threats), evil twins, Bluetooth Vulnerabilities and
Threats, countermeasures
3.   Mobile Device Security Models   05
The Android Security Model, The Android Sandbox, File-System Permissions,
Android SDK Security Features, Rooting and Unlocking Devices, Android
Permission Model, The Apple Security Model, Application Provenance, iOS
Sandbox,   Security Concerns, Permission-Based Access, Encryption,
Jailbreaking iOS, Trusted Execution Environment, Security Enclaves.
4.   Mobile Forensics   06
Introduction, Applying Forensic Processes and Procedures, Approach to
Mobile Device Forensics (NIST Framework), Standard Operating Procedure
Document, Collecting Mobile Devices from scene, Seizing Digital Device
Evidence, Mobile Forensic Tool, Mobile Forensic Analysis Report
5.   Analyzing SIM Cards   03
Smart Card Overview, SIM and UICC, SIM Card Analysis, File System UICC
Structure, Network Information Data Locations, User Data Locations
6.   Mobile OS Forensics   06
Android and iOS forensics, Forensic investigations of Popular Applications
on Android and iOS Platforms, Impact of Device Jailbreaking or Rooting on
User Data Integrity in Mobile Forensics, Mobile Devices Malware Forensics

Reference Books
1. Mohammed Moreb, Practical Forensic Analysis of Artifacts on iOS and Android Devices, 1st
Edition, Apress, 2022.
2. Rohit Tamma Oleg Skulkin Heather Mahalik Satish, and Bommisetty, Practical Mobile Forensics- Third
Edition: A hands-on guide to mastering mobile forensics for the iOS, Android, and the Windows Phone platforms,
4th Edition, Packt Publications, 2020.
Laboratory Work
