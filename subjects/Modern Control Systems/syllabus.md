Teaching Scheme   Evaluation Scheme

week)   week)   week)   (Marks-50)   (Marks -100)
2   2   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Physics, Mathematics
Course Objective
This course is designed for the students to grasp the underlying mathematics and its application in
modern control systems. The students are required to analyze practical control engineering
problems using classical and modern methods. The course also emphasizes synthesizing solutions
using scripting on a computational platform.
Course Outcomes
After completion of the course, the student will be able to -
1. Use the theoretical concepts in classical and modern control theory
2. Analyze the performance of a control methodology
3. Develop theoretical designs for controllers using modern methods
4. Analyze control designs for motion control
5. Synthesize the motion control and motion logic control solutions to practical problems
Detailed Syllabus
Unit   Description   Duration
Introduction
Dynamic system models, differential equations, DC motor, mass-spring-
1.   04
damper system, Laplace transforms, transfer functions, frequency response
functions
Classical Control Theory
2. Magnitude and phase equations, Bode plot, Root Locus, Routh Hurwitz   04
criterion, Nyquist stability, gain and phase margin
Controller Design
3. Open loop control, state feedback control, PID control in Laplace domain, gain   06
and phase compensators
Introduction to Modern Control Theory
4.   Matrix computations, State-space form, pole placement, Observer design,   06
observer based controller, state feedback control, PID control
Discrete Time Systems
5.   Discrete time systems, discretized continuous systems, time domain analysis,   04
Kalman filter
Performance Specifications
6.   Performance specifications, tracking and regulation, motion control with   04
trapezoidal velocity profile
Introduction to Advanced Topics
7. Optimal Control, H∞ Control, Linear Matrix Inequalities, semidefinite   02
programming
Total   30
