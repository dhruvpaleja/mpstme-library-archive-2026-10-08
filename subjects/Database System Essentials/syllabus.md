Course Objective
The objective of the course is to provide a comprehensive introduction to the fundamental concepts
for design and development of database systems.
Course Outcomes
After completion of the course, student will be able to -
1. Explain the basic concepts and the applications of database systems
2. Describe the fundamentals of data models depict a database system using ER diagram
3. Explain the relational database design principles
