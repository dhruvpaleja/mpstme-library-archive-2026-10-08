Data analysis is the method of examining, cleansing, and modeling data with the objective of determining

1. Apply concepts of data manipulation and wrangling
2. Analyze and work on raw data using analytical software
3. Create models using programming, descriptive statistics, and data architecture strategies
4. Interpret analytical results to support data-driven decision-making in various business domains.
5. Design visual representations of data using charts and statistical summaries to communicate
insights effectively.
