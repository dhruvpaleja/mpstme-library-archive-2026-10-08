Pre-requisite: Physics and Mathematics
Course Objective
This course develops an understanding of basic principles of wireless data transfer over the
internet and other networks. It emphasizes the software and hardware aspects of an IoT setup so
that the students are able to analyze practical problems with hardware and software tools, and IoT
protocols.
Course Outcomes
After completion of the course, students will be able to -
1. Explain the data transfer protocols used over the internet and other networks
2. Select the correct tools for solving problems in practice
3. Develop the basic framework of the setup to aid the design process
4. Analyze the overall system performance using the proposed architecture
5. Synthesize the architecture for optimum performance and required specifications
