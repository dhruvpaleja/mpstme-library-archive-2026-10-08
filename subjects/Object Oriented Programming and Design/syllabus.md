Course Objective
Introduces the basic concepts of object oriented programming concepts and related programming
skills.
Course Outcomes
After completion of the course, the student will be able to -
1. Differentiate between Procedural and Object oriented programming concepts
2. Describe fundamental concepts of object-oriented concepts.
3. Develop computer programs using object oriented concepts to solve the real life problems
4. Design a UML diagram for a given problem statement.
