2. Implement mechanisms for access control, cryptography and authentication,
3. Differentiate security mechanisms in programs, web applications and

Objectives:
This course is an introduction to the field of Cybersecurity. This course introduces various
aspects of cybersecurity to the students. Students will learn about various security threats
and countermeasures.
Outcomes:
After completion of this course, students would be able to
1. Analyze various cybersecurity threats and countermeasures
2. Understand various security technologies and mechanisms
3. Develop risk and Incident Management plan
4. Understand various professional, ethical and legal issues related to cybersecurity
