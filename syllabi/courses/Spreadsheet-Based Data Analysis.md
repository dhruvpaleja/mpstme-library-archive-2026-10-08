1   2   0   2   Marks Scaled to 50   --
Pre-requisite: Nil
Course Objective
The objective of this course is to introduce students to the fundamentals of spreadsheet tools used for data
handling and analysis. The course aims to develop basic to intermediate skills in organizing, cleaning,
analyzing, and presenting data using spreadsheets.
Course Outcomes
After completion of the course, students will be able to-
1. Explain the basic structure and features of spreadsheet software and manage worksheets and
datasets effectively (K1)
2. Apply formulas and built-in functions to perform calculations and basic data analysis tasks (K3)
3. Organize, clean, and validate datasets using spreadsheet tools and best practices (K3)
4. Analyze and present data using charts, summaries, and basic dashboards for effective
communication (K4)
Detailed Syllabus
Unit   Description   Duration
Introduction to Spreadsheets
Overview of spreadsheet software, Workbook and worksheet structure, Rows,
1.   columns, and cells, Data types (text, number, date, logical), Entering, editing, and   01
formatting data, Understanding datasets and tabular data, Saving, importing, and
exporting files
Basic Formulas and Functions
Cell referencing (relative, absolute, mixed), Arithmetic formulas, Aggregate functions
2. (SUM, AVERAGE, COUNT, MIN, MAX), Logical functions (IF, AND, OR), Text   02
manipulation functions, Date and time functions, Understanding and correcting
formula errors
Data Organization and Cleaning
Sorting and filtering data, Removing duplicates, Handling missing and blank values,
3.   03
Standardizing text and numeric formats, Data validation rules, Find and replace
techniques, Basic data quality checks
