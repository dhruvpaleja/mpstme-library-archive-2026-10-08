- Course as printed: Computer Applications in Civil Engineering - I (code 702CI0C023)

````text
Program: B Tech (Civil Engineering)   Semester: VI
Course: Computer Applications in Civil Engineering - I   Code: 702CI0C023
Teaching Scheme   Evaluation Scheme
Lecture   Practical   Tutorial   Internal Continuous   Term End
(Hours per   (Hours   (Hours   Credit   Assessment (ICA)   Examinations (TEE)
week)   per week)   per week)   (Marks - 50)   (Marks- ---)
0   2   0   0   Marks Scaled to 50   ---
Pre-requisite: Basic understanding and knowledge of civil engineering design and planning
Course Objective
The course aims to provide the knowledge, understanding and skills necessary to use computer
applications for civil engineering projects. It also aims at interpretation of the results obtained
using software and preparation of report.
Course Outcomes
After completion of the course, students will be able to –
1. Prepare a model for a part of infrastructure project in civil engineering
2. Analyse and design the civil engineering infrastructure project
3. Prepare the report to represent the output of the processed data
Detailed Syllabus
Unit   Description   Duration
Importance and need of software for modeling, analysis and design in Civil
1   Engineering field, Advantages and limitations of software, causes for errors,   02
validation of software results. Failures due to errors in modeling, data entry and
interpretation of software results.
Introduction to interactive design using software tools like STADD.Pro / Revit
Architectural software / EPANET AND MODFLOW.
2   28
Software application in various disciplines of Civil Engineering: Learning and
practice of any one software.
Total   30
Reference Books
1. Relevant Software manuals.
2. Relevant Indian standard codes.
Laboratory Work
Students will engage in a variety of in class assignments, group projects, and presentations
throughout the semester.
A group of 4-5 students will prepare a report and give detailed power point presentation on project
prepared, analysed and designed using software.
