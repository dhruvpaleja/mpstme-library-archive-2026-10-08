Course Objective:
To be familiar with processing of images, recognition of the pattern and their applications.
Course Outcomes:
1. Understand the fundamentals of image processing.
2. Compute and analyse effects of various image transformation techniques in spatial domains
and colour image processing.
3. Analyse images using image segmentation and morphological operations.
4. Analyse images using the concept of image registration.
