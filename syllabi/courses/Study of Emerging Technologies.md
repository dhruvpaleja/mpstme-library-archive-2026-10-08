## B TECH · Electronics and Telecommunication · AY 2015-16 · Sem 4

- Course as printed: Study of Emerging Technologies (code BTET04007)
- Source: `04_Syllabi_Archive/B TECH/2ND YEAR/EXTC/Sem_03/B Tech 2nd Year, (Extc), Sem III, Year 2015-2016.pdf`, page 32-33

````text
Program: _B. Tech. ( EXTC ) Semester : IV
Course: Study of Emerging Technologies Code : BTET04007
Teaching Scheme Evaluation Scheme
Internal Continuous Assessment
Lecture | Practical | Tutorial | Credit (ICA)
As per Institute Norms

0 Weightage

7 0 1 100%

Pre-requisite: Nil

Objectives:
1. To develop self learning as well as lifelong learning attitude.

2. To teach the importance of technical report writing.

3. To develop ability to collate and present the contents of a topic.

Outcomes:
After the successful completion of this course, the student will be able to
1. Select an appropriate topic on an emerging technology.
2. Identify the latest developments in the concerned topic.
3. Relate the effect of technology on benefits for society.
4. Summarize the topic into a technical report by discussing with team
members.
5. Make a group presentation on the report.

Detailed Syllabus:

A group comprising up to 3 students should identify the problem, definition the
scope of the seminar in consultation with a faculty member / mentor. While
choosing the topic the students should identify modern technology related to
subjects of previous or current trimesters.

Evaluation:

Each group is expected to maintain the log book. The log book needs to be
evaluated by the mentor every week as the part of continuous evaluation. Each
group must submit the report and make a presentation at the end of the trimester as
the part of trimester end exam. The end trimester exam would be conducted by two
examiners.

Project Report must contain:
1. Problem Definition

3. Project description
4, Details of development - Methods / Techniques / Data / Charts / Diagrams
5. Applications - Advantages and Limitations.
6. Project Code & Snapshots/Output.
7. References
````
