Pre-requisite: Programming concepts
Course Objective
The course provides opportunity to exposure to open source software philosophy and tools.
This course provides students with exposure to the design, creation Open Source Software
projects (Web Based/ Mobile based/ Desktop Based). Students will be introduced to the
historic intersections of technology and will become familiar with Open Source development
processes, tools and practices.
Course Outcomes:
After completion of the course, student will be able to:
1. Understand Open-Source Software (OSS) Philosophy and explore Linux Operating
System
2. Develop web application based/Mobile application based/ Desktop Application
based software using open source tools methodologies
3. Develop and use information system architectures, software platforms, and new
Application Programming Interfaces (APIs), frameworks in open source software
development
Detailed Syllabus:
Practicals based on the following topics:
1. Open Source Software (OSS) Philosophy: Understanding the FOSS Community and
FOSS Philosophy, Benefits of Community based Software Development, Guidelines for
working with FOSS community, Requirements for being open, free software, open
source software, FOSS Licensing Models, FOSS examples.
2. LINUX: Linux Installation and Hardware Configuration, Boot Process, Dual-Booting
Linux and other Operating, Systems, Kernel Options during Boot, X Windows System
Configuration, System Administration, (Server Administration, Backup and Restore
Procedures).
3. Programming Tools and Techniques: Libreoffice Tools; Samba: Cross platform;
Introduction about LAMP; Open Source UML Tools; Version Control Systems like SVN,
