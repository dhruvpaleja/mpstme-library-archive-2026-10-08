Prerequisite: Nil
Objectives:
This is an introductory course in excel. The course is designed to enable students to
understand and work on contemporary excel sheets and macros. The objective is to learn
how excel is user-friendly and can be used in almost all scenarios and domains.
Outcomes:
After completion of this course, students will be able to
1.   Understand simple and logical operations in Excel
2.   Use various excel functions based on real life examples.
3.   Categorize various tools to search, present and rectify data
4.   Analyse data using excel and also work on Macros
Detailed Syllabus: (Per session plan)
