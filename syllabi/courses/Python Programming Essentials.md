Course Objective
To equip students with foundational Python programming skills, covering syntax, control flow, data
structures, and libraries like NumPy and Pandas. To write modular code, handle exceptions, apply
object-oriented principles, work with regular expressions, manage databases using SQLite3, and create
interactive GUI applications with Tkinter for real-world problem-solving.
Course Outcomes
After completion of the course, the student will be able to -
1. Develop python programs using control flow statements and data structures
2. Apply concepts of regular expressions, exception handling and database
3. Apply Object-oriented concepts to solve a practical based scenario
4. Build basic interactive GUI applications
Detailed Syllabus
Unit   Description   Duration
1.   Basic and Control flow statements   04
Identifiers, Variable, Comments, Keywords, input(), print(), Arithmetic,
Relational, Assignment, Logical, Bitwise, Membership and Identity operator,
Conditional statements (if, if-else, if-elif-else, nested if), Loops in python (while,
for, nested loops), Loop manipulation statements (continue, pass, break, else)
2.   Data Structures   03
Defining, accessing values, deleting values, updating operations and built-in
functions/methods of (List, Tuple, Set and Dictionary), List and Dictionary
Comprehension.
3.   Python Libraries   03
NumPy to create one-dimensional and two-dimensional arrays and operations
on array, Pandas operations using (series, dataframes, read CSV).
4.   Functions and Exception Handling   06
Defining function, Calling function, Function arguments (args and kwargs),
recursive functions, Return statement, Scope of Variable, built-in functions
(Lambda, Map).
Types of errors, handling an exception, try, except, else, try-finally clause,
Argument of an Exception, Raising an Exception.
5.   Object Oriented Programming   06
Creating class and object, Constructors (Parameterized & Non-Parameterized),
self parameter, __init__, Overloading and Overriding, Single Inheritance,
Multiple Inheritance.
6.   Regular Expression and Database Connectivity   04
Match, Search, Replace functions, findall(), compile(), Regular Expression
patterns, Database connectivity using SQLite3 (Create, Insert, Update, Delete).
