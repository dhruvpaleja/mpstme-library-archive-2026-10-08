Course Objective
The objective of this course is to equip students with the knowledge and practical skills necessary
to understand, troubleshoot, and maintain computer hardware components effectively. The
course aims to ensure that students are capable of diagnosing hardware issues, performing
preventive maintenance, assembling, upgrading, and repairing computer systems.
Course Outcomes
After successful completion of the course, student will be able to -
1. Assemble and disassemble computer and laptop systems
2. Install and configure Windows and Linux OS
3. Install, diagnose and troubleshoot software and hardware issues
4. Perform preventive maintenance and hardware upgrades
Detailed Syllabus
Unit   Description   Duration
1.   Introduction   06
Computing process, Types of computing systems, computer hardware
components (motherboard, monitor, CPU, RAM, ROM etc.), types of
software, common OS functions, peripheral devices and their types
2.   Assembly of Desktop and Laptop System   08
Selection and installation of CPU, types of Memory (DRAM, SDRAM, DDR,
PATA, SATA, SSD etc), selection and installation of primary and secondary
memory, power supply and other peripheral devices for working desktop
and /or laptop systems
3. OS Installation   04
Installing Windows and Linux OS, booting process, partitioning, file system
and creating bootable media, troubleshooting OS related issues.
4.   Troubleshooting issues   05
Troubleshooting methodology, Troubleshooting Problems Related to
Motherboard, CPU, RAM, and Power, troubleshooting hardware, software
and other peripheral device issues.
5.   Preventive Maintenance and Hardware Upgrades   04
Maintaining Operating Systems, scheduling maintenance, optimising OS
performance, backup and restore, third party maintenance software.
