Pre-requisite: Computer Networks
Objectives:
1. To understand data security and message authentication in computer communication
2. To learn various cryptographic algorithms
3. To understand various attacks on cryptographic algorithms
4. To know applications of cryptography for data and system security. The internet and
wireless network security.
Outcomes:
After completion of the course, students would be able to:
1. Identify the aspects of data security.
2. Use the different standards of private key encryption and analyse security attacks
3. Apply the knowledge of number theory for public key encryption standards.
4. Know cryptographic data integrity algorithms and key management.
