Practical Exam
Pre-requisite: Basic knowledge of computer and programming.
Course Objective
To introduce object-oriented programming paradigm to solve engineering / industry problems.
To understand and differentiate between object-oriented programming and procedural
programming.
Course Outcomes
After completion of the course, the student will be able to -
1. Understand of fundamental programming concepts, including data types, variables and
operators
2. Executing flow control and arrays, to develop structured and efficient Java programs
3. Implement object-oriented programming principles such as classes, inheritance, interfaces,
and access control to design modular and reusable Java applications
4. Apply generics to create flexible and type-safe data structures and methods, enabling
improved code reusability and maintainability
5. Analyze and handle exceptions effectively using try-catch-finally constructs, custom
exceptions, and exception propagation techniques to ensure robust and error-free program
execution
