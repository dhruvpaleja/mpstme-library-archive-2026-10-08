Pre-requisite: Data Wrangling/Data Wrangling Fundamentals and Practices
Course Objective
The objective of this course is to introduce students to the fundamental concepts of data engineering.
The course provides a conceptual understanding of data systems, data architecture, data movement,
data preparation, and basic data pipeline concepts using structured datasets. Emphasis is placed on
understanding how data flows through different stages in a data system, ensuring data quality and
consistency.
Course Outcomes
After completion of the course, students will be able to-
1. Explain the structure and components of data systems and basic architectural concepts used in
data-driven applications (K1)
2. Describe different data sources and ingestion mechanisms involved in moving data into a data
system (K2)
3. Apply data structuring and preparation techniques to organize datasets for processing across
multiple stages (K3)
4. Analyze datasets to ensure data quality, consistency, and reliability during data preparation and
integration (K4)
