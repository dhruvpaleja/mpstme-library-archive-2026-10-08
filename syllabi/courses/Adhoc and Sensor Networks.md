Program: MBA Tech. (EXTC)   Semester : VIII
Course: Adhoc and Sensor Networks   Code : BTET08018
(Departmental Elective – 4)

3   2   0   4   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Communication Network and Wireless Communication.
Objectives:
1. To understand the basics of adhoc network and wireless sensor networks.
2. To recognize the routing mechanism and security concerns in adhoc networks.
Outcomes:
After completion of the course, students would be able to:
1. Explain the concepts, network architectures and applications of Adhoc and
wireless sensor networks
2. Analyse the protocol design issues of Adhoc and sensor networks
3. Design routing protocols for Adhoc and wireless sensor networks with respect to
some protocol design issues
4. Understand the wireless sensor network architecture, MAC protocol and
standards.
Detailed Syllabus:
Unit   Description   Duration
1   Adhoc Wireless Networks:   04
Introduction, Issues in Adhoc Wireless Networks, Adhoc Wireless
Internet, Applications.

Networks, Classifications of MAC Protocols. Contention-Based
Protocols, Contention-Based Protocols with Reservation Mechanisms,
Contention-Based MAC Protocols with Scheduling mechanisms.
