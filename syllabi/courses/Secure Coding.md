Pre-requisite: Fundamentals of C Language
Course Objective
This course teaches the fundamentals of secure programming in C. Students will learn how a C
program runs “under-the-hood” by analysing at the machine-level representation. The coding
standards and design principles of secure programming are explored so that security can be built-
in the design time to avoid security vulnerabilities.
Course Outcomes
After completion of the course, the student will be able to -
1. Explain the fundamentals of secure programming
2. Analyse C programs for security vulnerabilities
3. Implement security attacks
Detailed Syllabus
Unit   Description   Duration
1.   Introduction   04
Philosophy of Secure Programming, Security Policies and Procedures,
Motivation behind Software Security, Examples of Vulnerabilities, A Tour of
Computer Systems, Secure Programming Design Principles.
2.   Representing Information   04
Bits and Bytes, Hexadecimal Notation, Addressing and Byte Ordering, Integer
Security, Integer Arithmetic, Integer Overflow and Security Vulnerabilities.
3.   Machine-Level Representation of C Programs and Optimizing Program   08
Performance
Conditional Statements, Switch-Case Statements, Loops, Procedures, Array
Allocation and Access, Eliminating Loop Inefficiencies, reducing Procedure
Calls, Eliminating Unneeded Memory References, Loop Unrolling, Enhancing
Parallelism, Memory Performance, Stack-based Buffer Overflow.
4.   Data Pointer and Function Pointer Vulnerabilities   04
Smashing the stack by exploiting pointers, Dynamic Memory Allocation and
security.
5.   Linking   03
Load-time exploitation, Basics of static and dynamic linking.
6.   Format String Vulnerabilities   03
Stack layout of variadic functions, Exploit the formatted output string and
buffer overflow vulnerabilities.
