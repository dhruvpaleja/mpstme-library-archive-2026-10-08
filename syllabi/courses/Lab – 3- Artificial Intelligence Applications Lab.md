Course Objective
This subject will enable students to apply object detection and OCR models using pre-processed
datasets while optimizing the performance of these models in edge computing environments. Students
will evaluate system performance by utilizing advanced optimization techniques such as parallel
processing and caching, and will gain the ability to create secure, full-stack solutions by integrating
front-end and backend applications for real-time data analysis and insights.
Course Outcomes
After completion of the course, students will be able to –
1. Develop and evaluate object detection and OCR models using pre-processed image datasets
2. Implement edge computing environments and optimize model performance on embedded
devices
3. Utilize performance optimization techniques such as parallel processing, caching, and
batching to enhance system efficiency
4. Build secure, integrated full-stack solutions by connecting front-end and backend applications
for data analysis and insights
