Pre-requisite: Programming for Problem Solving (702CO0C002)   , Object Oriented
Programming and Design (702CO0C005)
Course Objective
Create web pages and provide client-side validation. Develop entity relationship data
model, mapping it to relational database. Query relational database to obtain required data
using SQL. Understand Object oriented concepts like data inheritance, abstraction,
encapsulation, etc. Introduce the emerging field of big data analytics.
Course Outcomes
After completion of the course, the student will be able to -
1. Design static & dynamic web pages using HTML5, CSS3, JavaScript and JQuery
2. Design relationship models for real life entities
3. Apply SQL queries to relational databases.
4. Solve computational problems using basic constructs like if-else, decision structures,
loops etc
5. Develop GUI based application using programming constructs
6. Understand the key differences in traditional data analytics and big data analytics
