Pre-requisite: Programming for Problem Solving (C programming language).
Objectives: This course is designed to enable students for web application development
with the understanding of fundamental principles of web technologies. Students will
learn to develop Web applications using HTML, CSS, and rich interactive using PHP as
server side technology.
Outcomes: After completion of the course, students would be able to :
1.   Design user interface using HTML and CSS.
2. Design responsive and interactive web pages using client side, server side
technologies
3.   Understand and implement front end and back end connectivity.
Detailed Syllabus: ( per session plan )
Unit Description   Duration
1 HTM: Introduction to Hypertext Markup Language, Web Page   6
Structure, Basic Tags, attributes, heading, paragraphs, formatting,
images, Links, Lists, Frames, Tables, Forms, HTML5- new elements,
Input Types, media.
2   Cascading Style Sheets: Introduction to styles, Syntax & Rules,   5
External, Internal/Embedded, Inline Style Sheets, conflicting styles,
Property Value Forms, Font Properties, List Properties, Color &
Background Properties, Text Properties, Image as bullets, Introduce
different Box Model, CSS3- Backgrounds, Text effects, 2D & 3D
transforms, transitions, animations. Responsive Websites design with
HTML5 and CSS3.
