Pre-requisite: Engineering Mathematics – III and IV
Course Objective
The objective of this course is to enable students to understand and apply advanced concepts in
machine learning to real life problems.
Course Outcomes
After completion of the course, student would be able to-
1. Explain advanced concepts in machine learning
2. Map real world problems to a machine learning problem definition and select appropriate
machine learning algorithm
3. Design applications using machine learning techniques
4. Evaluate the performance of the applications
Detailed Syllabus
Unit   Description   Duration
1   Overview of ML concepts   4
Supervised and unsupervised methods Probability theory, Decision theory,
Information theory, Linear Algebra
2   Concept Learning, Minimum Description Length (MDL),Hidden Markov   6
Models (HMM), Generalized Linear Models, extensions of linear models
Polynomial regression, step functions, regression splines, smoothing splines,
local regression, generalized additive models (GAMs)
3   Graphical Models   4
Bayesian Belief Networks, PAC Learning, SOM, VC-Dimension and Monte
Carlo Simulation
4   Genetic Algorithms   5
Hypothesis space search, Genetic programming, Models of evaluation &
learning
5   Reinforcement Learning   5
Q Learning, Non-deterministic rewards & actions, Temporal difference
learning, Generalization, Active Learning, Metric Learning
6   Deep Learning overview   3
Single and multi-layer neural networks, convolutional neural networks,
recurrent neural networks, when to use deep learning
