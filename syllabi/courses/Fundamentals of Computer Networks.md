Objectives:   This is an introductory course in computer network to provide
fundamental knowledge of computer networks through the network reference model.
Outcomes: After completion of the course, students would be able to:
1. Discuss the fundamental concepts in computer network.
2. Differentiate between different ISO-OSI model layers,
3. Implement various routing and congestion control algorithms.
4. Use networking tools to observe and analyze behaviors of networking protocols.
