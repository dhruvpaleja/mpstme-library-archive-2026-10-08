Course Objective
1. To provide the fundamental knowledge of Image processing and related algorithms
involved in it.
Course Outcomes
After completion of the course, the student will be able to -
1. Outline the fundamentals of image processing
2. Compute and analyse effects of various image transformation techniques in spatial and
frequency domains
3. Analyse images using image segmentation and morphological operations
4. Compress the images using basic transforms, wavelets
Detailed Syllabus
Unit Description   Duration
1.   Digital Image Processing Systems   2
Introduction, Fundamental steps of image processing, Display Image
Sampling and quantization, Basic relationships between pixels. Types of
images: Monochrome, grey, colour.
2. Image Enhancement in the Spatial domain   2
Grey level transformations, Histogram processing, Arithmetic and logic
operations, Spatial filtering: Introduction, Smoothing and sharpening
filters.
3. Image Segmentation, Representation and Description   3
Detection of discontinuities, Edge linking and Boundary detection,
Thresholding, Region based segmentation, Representation – Chain
Codes, polynomial approximations, Signatures, Boundary Descriptors,
Regional Descriptors
4.   Morphological Image Processing   2
Introduction, Dilation, Erosion, Opening, closing, Hit –or-Miss
transformation, Morphological algorithm operations on binary images
and Morphological algorithm operations on gray-scale images.
5. Image Transforms   2
Introduction to Fourier transform, Walsh transform, Hadamard
transform, Discrete Sine transform, Discrete cosine transform,.
Frequency domain filters: Smoothing and Sharpening filters,
6.   Wavelets and Multiresolution Processing   2
STFT, need of wavelets, Image pyramids, Filter Banks, Haar transform,
Application of wavelets.
