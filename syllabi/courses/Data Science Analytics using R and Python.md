Objectives
To understand the basics of the top data analytical language – Python and R. To learn data
cleaning and manipulation. To be able to read various data and use various data structures to
store and work on them. To visualize the data into charts.
Course Outcomes
After completion of the course, students would be able to -
1. Analyze and work on raw data using python and R,
2. Design charts and derive desired outputs,
3. Simplifying the data and manipulating them to model as required,
4. Discuss examples with case study.
