Pre-requisite: Object Oriented Programming and Design
Course Objective
The course is designed to provide basic knowledge of Python, to learn why Python is
useful scripting language and how to design and program Python applications.
Course Outcomes
After completion of the course, the student will be able to -
1. Write program to solve computational problems using python data structures
2. Implement file handling operations effectively in python programming
3. Develop real life solutions using core and object-oriented python concepts
4. Interpret data using NumPy and Pandas library
Detailed Syllabus
Unit   Description   Duration
1   Introduction to Python   03
Installation, Features, Python Interpreter and its working, Syntax and
Semantics, comments, imports, indentation, variables, data types, math
arithmetic, operators (comparison, logical, bitwise), expressions, print,
formatting print, generating random numbers.
2   Python Data Structures & Flow Control   06
Strings, Lists, Dictionaries, Tuples, Sets; Slicing; properties, operations and
methods of these data structures.
Conditional blocks using if, else and elif, Simple For loop, For loop using
Ranges, While loops, Loop manipulation using Pass, Continue, Break
List and dictionary comprehension.
3   Python Functions   05
Defining and calling functions, return, scope, function arguments (args and
kwargs), recursive functions; Built-in functions: Lambda, Map, Filter,
Reduce, Zip, Enumerate.
4   File and Exceptional Handling   04
File I/O read/write operations, open, close, with, seek, tell; manipulating files
and directories
Exception, Types of errors, handling an exception, try, expect, else, try-finally
clause, Argument of an Exception, Raising an Exception.
5   Classes and Objects   04
Class definition, object creation, class variables and methods, accessing class
attributes, meaning of self, __init__, inheritance, overriding super class.
6   Regular Expression and GUI with Python   03
Regular Expressions, Match function, Search function, Matching vs
Searching, Wildcard
