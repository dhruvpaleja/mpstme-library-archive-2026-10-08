Course Objective
The course objectives focus on developing expertise in Teamcenter architecture, organizational
management, workflow configuration, BMIDE-based data model setup, and utility usage for various
system requirements.
Course Outcomes
After completion of the course, the student will be able to –
1. Gain in depth knowledge of Teamcenter 2 tier and 4 tier architectures
2. Use organization application to create company organization (employee, user, group, role)
3. Create workflow process template and monitor them
4. Configure Teamcenter using BMIDE data model configuration
5. Use utilities for various requirement
