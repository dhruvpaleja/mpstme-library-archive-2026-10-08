Pre-requisite: Programming for Problem Solving
Course Objective
The course aims to prepare students to develop self-learning attitude, practical knowledge of
programming language/modern technology according to the engineering applications.
Course Outcomes
After completion of the course, the student will be able to -
1. Implement the use of basics Python syntax
2. Create Graphical user interface in Python
3. Implement open source numerical libraries to build engineering applications
Detailed Syllabus
Unit   Description   Duration
1.   Introduction to Python   04
Installation and Working with Python, Understanding Python variables Python
basic Operators, Understanding python blocks, Python Data Types: Declaring and
using Numeric data types: integers, float, complex, Using string data type and
string operations.
2.   Control Flow   06
If, if-elif-else, loops, for loop using ranges, string, Use of while loops in python,
Loop manipulation using pass, continue, break and else, Programming using
Python conditional and loops block, Python arrays.
3.   Data Structures   06
List Operations, Slicing, Methods; Tuples, Sets, Dictionaries, Sequences.
Comprehensions, Dictionary manipulation, list and dictionary in build functions
4.   Functions   08
Calling Functions, Passing Arguments, Keyword Arguments, Default Arguments,
Variable-length arguments, Anonymous Functions, Fruitful Functions (Function
Returning Values), Scope of the Variables in a Function - Global and Local
Variables. Powerful Lamda function in python.
5.   Numpy & Pandas   06
Introduction to Numpy, Create 1D array & 2D array, Introduction to pandas,
Pandas data structure:- series , data frame
Total   30
