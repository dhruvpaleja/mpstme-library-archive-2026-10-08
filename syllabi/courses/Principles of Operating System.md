1.Describe fundamental concepts of Operating system
2.Apply process management strategies
3.Apply memory, I/O and file management strategies
Detailed Syllabus: ( per session plan )
Unit Description   Duration
1   Introduction: Concept of Operating Systems (OS), Generations of OS,   4
Types of OS, OS Services, Interrupt handling and System Calls, Basic
architectural concepts of an OS, Concept of Virtual Machine, Resource
Manager view, process view and hierarchical view of an OS.
2   Process and Process Scheduling: Definition, Process Relationship,   8
Different states of a Process, Process State transitions, Process Control
Block (PCB), Context switching, Thread: Definition, Various states,
Benefits of threads, Types of threads, Process Scheduling: objectives,
Types of Schedulers, Scheduling criteria, Pre-emptive and non-pre-
emptive scheduling algorithms Real Time scheduling: RM and EDF
3   Process Concurrency and IPC: Inter-process Communication:   6
Concurrent processes, precedence graphs, Critical Section, Race
Conditions, Mutual Exclusion, Hardware Solution, Semaphores, Strict
Alternation, Peterson’s Solution, The Producer / Consumer Problem,
Event Counters, Monitors, Message Passing, Classical IPC Problems:
Reader’s & Writer Problem, Dinning Philosopher Problem, Barber’s
shop problem

4   Deadlock: Definition, Necessary and sufficient conditions for   4
Deadlock, Deadlock Prevention, Deadlock Avoidance: Banker’s
algorithm, Deadlock detection and Recovery.
5 Memory Management:   Basic   concepts, Memory   allocation:   8
Contiguous Memory allocation – Fixed and variable partition– Internal
and External fragmentation and Compaction. Basics of Virtual
Memory – Hardware and control structures – Locality of reference,
Page allocation, Partitioning, Paging, Page fault, Working Set,
Segmentation, Demand paging, Page Replacement algorithms:
Optimal, First in First Out (FIFO) and Least Recently used (LRU).
6   I/O Management and Disc Scheduling: I/O devices, Device   5
controllers, Direct Memory Access, Principles of I/O, Disk structure,
Disk scheduling - FCFS, SSTF, SCAN, C-SCAN, LOOK and C-LOOK,
RAID
7   File Management: Concept of File, Access methods, File types, File   5
operation, Directory structure, File System structure, Allocation
methods (contiguous, linked, indexed), Free-space management (bit
vector, linked list, grouping), directory implementation (linear list,
hash table), efficiency and performance.
8   Case study: Comparison of Windows and Unix, UNIX OS: file system,   5
shell, filters, shell programming, programming with the standard I/O,
UNIX system calls.
Total   45
