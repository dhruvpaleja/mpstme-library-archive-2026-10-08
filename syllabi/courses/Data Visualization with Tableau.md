Objectives
To visualize the data using BI tools by understanding various factors involved in developing
the charts. To train on using various visual charts for unbiased and effective conveying of
information. Getting familiar with the Tableau tools and its various functionalities.
Course Outcomes
After completion of the course, students will be able to -
1. Design the right chart for representing the data,
2. Analyze data internally and produce interactive dashboards in Tableau,
3. Demonstrate connecting python / R with Tableau environment to integrate information,
4. Summarize to enhance the visual narrative.
