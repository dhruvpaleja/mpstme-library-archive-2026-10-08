Pre-requisite: Knowledge on types of application architecture
Course Objective
The course aims to provide students with hands-on experience in building and deploying GenAI-based
applications. Students will learn to work with large language models, implement retrieval-augmented
generation (RAG) techniques, and evaluate the performance of AI models. Additionally, the lab covers
advanced topics like model fine-tuning, performance evaluation, and automation of software
development tasks using AI.
Course Outcomes
After completion of the course, students will be able to –
1. Compare monolithic and microservices architectures, evaluating their suitability for AI
applications.
2. Implement Kubernetes for managing and deploying AI models in production environments,
demonstrating its core functionalities.
3. Analyze the role of APIs in integrating AI models into systems, providing examples of their
practical usage.
4. Apply MLOps principles to streamline the machine learning lifecycle, focusing on data
preparation, deployment, and monitoring for effective optimization.
Detailed Syllabus
Unit   Description   Duration
Utilize a large language model (such as GPT-3.5), execute queries, and develop
Lab 1 a program allowing adjustments to parameters like Temperature, Top P, and   08
Max Tokens. Implement methods to make the output more deterministic.
Identify basic metrics for evaluating large language model responses (e.g.,
Lab 2   toxicity, bias). Write a short program to calculate scores for these metrics based   04
on model outputs.
Create a program for keyword-based search that takes any text file as input,
Lab 3   dynamically provides a "keyword," and evaluates if the algorithm can   08
effectively locate it.
Build a program using a vector database and embedding technique to perform
Lab 4   search on a given text file. Input queries and text files as inputs to retrieve   04
relevant answers.
Collect 2-3 medical reports, store them, and develop a program that
Lab 5   dynamically reads these files, extracts metadata, and saves questions for   04
information retrieval. Store the questions in a database and an Excel file.
