Pre-requisite: Physics and Mathematics
Course Objective
The course develops an understanding of the process of data mining leading to deriving
meaningful conclusions. It emphasizes practicing the tools of data analysis so that the students are
able to analyze practical problems with statistical and predictive modeling.
Course Outcomes
After completion of the course, students will be able to -
1. Explain the data mining and analysis processes
2. Select the correct tools for solving problems in practice
3. Develop the basic framework of the algorithm to aid design process
4. Analyze data mining efficiency and precision avoiding pitfalls
5. Synthesize methods for unstructured data sets for the underlying pattern
