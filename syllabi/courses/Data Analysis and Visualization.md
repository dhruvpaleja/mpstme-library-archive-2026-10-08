Course: Data Analysis and Visualization   Code: 701CO0C024

week)   week)   week)   (Marks - 50)   (Marks - 50)
1   2   0   2   Marks scaled to 50   Marks scaled to 50
Practical Examination
Prerequisite: Basic Programming Concepts
Course Objective
To equip students with comprehensive skills in data analysis and visualization techniques, enabling them
to collect, process, analyse and visualize data using industry-standard tools like Python and Power BI.
Course Outcomes
After completion of the course, the students will be able to -
1.   Illustrate the basic principles of data analysis and statistical methods
2. Understand the basic syntax and data structures in Python
3. Analyse the data using Exploratory data Analysis techniques using Pandas
4. Create data visualizations using Power BI
Detailed Syllabus
Unit   Description   Duration
1.   Understanding Data   02
What is data, Types of data (numbers, text, dates), Simple data organization in
Excel, Introduction to basic statistics (mean, median, mode),Reading and
writing CSV files
2.   Getting Started with Python   03
Basic Python programming, Installing Python and libraries, Introduction to
Jupyter Notebook, Working with lists and dictionaries
3.   Introduction to Data Analysis   03
Introduction Numpy Array, Difference between list and Numpy Array,
Operations on 1-D and 2-D Numpy Array
4.   Data Analysis using pandas   03
Introduction to Pandas and DataFrame, Importing and Exporting Data,
Preprocessing of Data, Data cleaning, Data normalization in python,
Exploratory data Analysis
5.   Introduction to Data Visualization and Power BI   04
Introduction to Data Visualization, Installation of Power BI, Data
Modeling and its Importance, Data Transformation, Query editor, Data
cleaning, manipulate data using formulas in Power BI, Queries, data
visualizations in Power BI using standard charts and custom visuals.
Total   15
