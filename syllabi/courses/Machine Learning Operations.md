Pre-requisite: Basic understanding of neural networks and ML Principles & Python programming.
Knowledge on mathematical concepts, including linear algebra, calculus, and probability.
Course Objective
The course aims to develop students' ability to design end-to-end ML production systems, build and
manage data pipelines, and create models suited for different deployment environments. It also focuses
on implementing and monitoring scalable ML pipelines that meet production and infrastructure
requirements.
Course Outcomes
After completion of the course, students will be able to –
1. Understand the key components and stages of the ML lifecycle, comparing ML modeling and
deployment cycles.
2. Evaluate the data lifecycle, focusing on data collection, labelling, preprocessing, and feature
engineering techniques.
3. Design and implement ML pipelines for high-performance model management, including neural
architecture search and resource optimization.
4. Develop and deploy ML models by building scalable infrastructure and ensuring model
availability for batch and real-time inference.
5. Implement modern MLOps practices, automate workflows, and establish model monitoring and
logging procedures to maintain accuracy in production.
