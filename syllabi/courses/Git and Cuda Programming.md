Pre-requisite: Python Programming
Course Objective
The course aims to introduce students to version control using Git for collaborative software development
and provide foundational knowledge of GPU architecture. It further equips learners with practical skills
to program using CUDA in Python through Numba/CuPy, enabling them to build and optimize GPU-
accelerated applications suitable for AI and data-intensive workloads.
Course Outcomes
After completion of the course, students will be able to -
1. Apply basic Git commands to create repositories, track changes, and manage version control.
2. Use Git branching, merging, and collaborative workflows involving pull requests and remote
repositories.
3. Explain GPU architecture and develop basic CUDA programs involving kernels, blocks, threads,
and grids.
4. Implement CUDA-accelerated programs in Python using Numba or CuPy for computational
tasks.
5. Optimize CUDA kernels and apply GPU acceleration to AI and machine-learning workloads.
