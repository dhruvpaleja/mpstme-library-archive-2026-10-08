Course Objective
To learn about security of operating systems and how to enforce mandatory access control.
Also to study database security and their applications
Course Outcomes: After completion of the course, student will be able to:
1. Understand the concepts of Operating System Security
2. Discuss concepts of Multics, Access Control and Secure OS
3. Explain how Security is implemented in Windows and Unix OS
4. Implement concepts of database security
