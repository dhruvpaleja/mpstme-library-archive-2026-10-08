Course Objective
To provide insights about visual Data analytics concepts, tools, and finding patterns in the data
in the form of dashboards.
Course Outcomes
After completion of the course, students will be able to,
1. Import and Clean data using programming.
2. Prepare data in a uniform format for visualization using programming
3. Analyze data using charts and graphs
4. Design and implement a dynamic dashboard (Report)
Detailed Syllabus
Unit   Description   Duration
1   Getting started with Data visual analytics   1
Introduction to Visual Analytics concepts, Role of Data Visual Analytics
for Business, Job Roles in Data Visual Analytics
2   Preparing data for visualization   4
Accessing Data, Formatting Data Values, Conditional Processing, Sorting
Data, Grouping Data, Controlling Input and Output Operations on Data,
Concatenation and Merging of Data.
3   Analyzing Data for Visualization   2
Importing and selecting data items, Handling-Missing Data, Enhancing
and Analyzing Data, Analysing Data Errors
4   Visual Analytics:   4
Different types of data Items in analytics, Data Exploration with charts and
graphs: Bubble plot, bar chart, pie chart, line chart, scatter plot, creating
data item and applying filters, basic data analysis using graphs, Selection
of Charts using data Items, working with gauges, working with tables
5.   Designing Dynamic Dashboard   2
Designing Dashboards, working with graphs, establishing Interactions,
working with gauges, working with tables, Working on Links and actions
in the dashboard.
6.   Case Study   2
Creating a dashboard for a sample business scenario.
