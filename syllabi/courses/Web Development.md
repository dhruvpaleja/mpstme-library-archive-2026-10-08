Course Objectives-
This course enables students to develop modern web applications by leveraging latest technologies. Builds strong
foundation in students making them job ready as per industry requirements by applying foundation paradigms,
building strong expertise to develop end to end application - web frontend and backend development.
Course Outcomes- After completion of the course, students would be able to:
1. Develop responsive web pages using HTML5 and CSS3 (K-3)
2.Implement client-side scripting with JavaScript for DOM manipulation and event handling (K-4)
3.Build server-side applications using Node.js for asynchronous application (K-5)
4. Implement routing and form data parsing using Node.js modules. (K-6)
