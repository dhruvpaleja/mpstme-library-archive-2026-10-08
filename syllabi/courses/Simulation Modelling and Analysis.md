Program: B Tech and MBA Tech Data Science, B Tech CSE(DS)   Semester: V/ VI
Course: Simulation Modelling and Analysis   Code: 702DB0E020
Teaching Scheme   Evaluation Scheme
Lecture   Practical   Tutorial   Internal Continuous   Term End
(Hours   (Hours   (Hours per   Credit   Assessment (ICA)   Examinations (TEE)
per week)   per week)   week)   (Marks -50)   (Marks - 100)
2   2   0   3   Marks Scaled to 50   Marks Scaled to 50
Pre-requisite: Probability theory
Course Objective
To acquaint the students with various modeling and simulation techniques for discrete, dynamic and
stochastic systems. It will focus on the important aspects of simulation study, including modelling,
simulation languages, validation, and output data analysis.
Course Outcomes
After completion of the course, students will be able to -
1. Understand the fundamentals of system modeling and simulation techniques, including
deterministic/stochastic systems, discrete event simulation, continuous simulation, and Monte
Carlo methods.(L2 – Understand)
2. Apply discrete event simulation techniques using time-advance mechanisms and event-driven
approaches to model systems such as single-server queues.(L3 – Apply)
3. Develop and simulate real-world systems using GPSS by utilizing blocks, transactions, user-
defined functions, and logic switches.(L4 – Develop)
4. analyze random numbers and variates using statistical tests (chi-square, runs test), and select
appropriate probability distributions for simulation input modeling.(L4 – Analyze)
5. Evaluate simulation results using statistical techniques such as confidence intervals, variance
reduction methods, and experimental design to compare system alternatives. (L5 – Evaluate)
Detailed Syllabus
