Course Objective
This course introduces approaches used to solve problems using computing, which are not based
on traditional hardcoded programs. These solutions are based on mathematical modeling of
problem. It helps students to gain insight in developing more flexible applications and effective
solutions especially in context of complex problems.
Course Outcomes
After completion of the course, students would be able to-
1. Explain various problem solving methods and tools using soft computing.
2. Describe Fuzzy logic, Genetic Algorithm concepts and its applications.
3. Explain working of different Machine learning techniques, Artificial Neural Networks (ANN)
and their applications.
