Course Objective
This course provides fundamental knowledge of Teamcenter, including object management, product
structure creation, workflow monitoring, and data restriction using access management. It also covers
NX CAD integration for creating and managing engineering data efficiently.
Course Outcomes
After completion of the course, the student will be able to –
1. Gain knowledge of Basic Fundamental of Teamcenter
2. Create, search or modify objects in Teamcenter
3. Understand the workflow process and be able to monitor it effectively, and gain knowledge of data
restriction through access management."
4. Integrate NX CAD software and Teamcenter product data management to create and manage NX
parts and other engineering data.
5. Create, revise, find, view and manage product data.
