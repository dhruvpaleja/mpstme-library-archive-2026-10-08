Course Objective
This course introduces the fundamentals of Plant Simulation, focusing on layout optimization, automation,
and factory efficiency. Learners will develop skills in throughput analysis to enhance production
performance and resource utilization. The course covers strategic planning methods to optimize workflows,
ensuring efficient and scalable factory operations.
Course Outcomes
After completion of the course, the student will be able to –
1. Understand the fundamental principles of plant layout optimization and its impact on operational
efficiency.
2. Analyze factory throughput to identify bottlenecks and opportunities for efficiency improvement.
3. Evaluate the effectiveness of different automation strategies in enhancing factory performance.
4. Create innovative layout solutions by integrating optimization, throughput analysis, and automation
principles
Detailed Syllabus
Unit   Description   Duration
1.   Basics of the Plant Simulation Interface in NX   07
Basics of plant simulation user interface, basic plant simulation interface, object-
oriented modeling strategies, basics of material flow objects, hierarchy, icons, and
inheritance.
2.   Advanced Plant Simulation: Object Modeling and Resource Management   07
Modelling of objects, modeling buffers, assembly lines and roads, Kanban, and
failures, resource objects (i.e. workers and shift calendars), resource objects (i.e.
workers, shift calendars, foot paths, etc.).
3.   Modeling Basic Conveying Systems in NX   06
Material movement and units, basic conveying systems (length-oriented objects),
other objects (i.e. information objects, user interface object, mobile units).
4.   Optimizing Plant Performance: Analysis and Customization   06
Analysis tools, sankey, bottleneck analyzer, and experiment manager basics,
customizing object logic (method creation), methods for data collection and
evaluation.
5.   Advanced Data Integration: Importing and Managing External Data   04
Additional topics, methods for interfaces (excel, DDE, basics of other interfaces),
data acquisition from external files and systems.
